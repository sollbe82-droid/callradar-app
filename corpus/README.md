# 콜레이더 학습 corpus 폴더 — 파서/OCR 진화용

대표님이 실물 이미지를 **유형별 하위폴더**에 넣어주세요. 이걸로 (원본 → OCR → 올바른 값) 정답쌍을 만들어 파서를 개선·검증합니다.

## 넣는 곳 (유형별)
- `chat_call/` — 오픈톡방 등 **제보콜 채팅 스샷** (현재 인식율 낮음 → 최우선)
- `daily_close/` — **일일마감 명세서** 사진
- `gas/` — **가스비(LPG) 영수증**
- `payslip/` — **급여명세서** 사진
- `etc/` — 그 외

## 팁 (인식율 잘 나오게)
- 가능하면 **글자 영역이 선명**하게, 기울기·그림자 적게.
- 파일명은 아무거나 OK. 같은 건 여러 장이어도 좋아요(많을수록 좋음).
- 개인정보(이름·전화·차량번호)는 corpus 처리 시 **마스킹**합니다.
