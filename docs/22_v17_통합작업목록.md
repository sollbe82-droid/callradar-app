## ★ 오늘 이미 코드 반영됨 (v17 빌드에 자동 포함)

- **최소입력**: 과거기록 저장 시 **목적지 강제 제거** → 날짜+금액만으로 저장, 빈 목적지는 `미정`. (`RecordsScreen` 337행)

## 1. 설정 초기화 버그 (신뢰 직결 · 최우선) — "수치 다 검토"
- **현상:** 공유설정(오픈방 링크·문구) 등 저장돼도 **업데이트하면 초기화**. 몇몇 설정 공통.
- **원인 후보:** 정산설정 로드가 **서버값으로 로컬 prefs를 덮어씀**(`MoreScreen` 567행) → 서버에 없는 항목은 기본값으로 리셋. 서버 저장 항목/미저장 항목 불일치(예: 개별 수수료 `fee_kakao/uber/tmoney`는 로컬만, 서버엔 합산 `commission_rate`만).
- **조치:** 전 설정 저장/로드 **감사**. 규칙 통일 — (a) 로컬 우선·서버는 병합(빈 서버값이 로컬 못 덮음), (b) 저장하는 모든 키를 서버에도 왕복. 공유설정은 로컬 유지 확인. 대상 키: `share_room_url, share_promo, fee_kakao/uber/tmoney, daily_sanap, lpg_subsidy, gas_method, gas_fixed, gas_reduction, lpg_price, profit_share, lpg_refund_rate, work_days, annual_leave, day_start_hour, daily_expense`.

## 2. 플랫폼별 수수료 — 소수점 지원
- **현상:** 카카오/우버/티머니 수수료가 정수만(입력 `isDigit()`만, `MoreScreen` 592~596행), 저장 `putInt`.
- **조치:** 입력에 소수점 1자리 허용(예 3.3%), 저장 `putFloat`, 계산·서버 `commission_rate` 숫자(numeric)로. 급여 역산에 소수 반영.

## 3. LPG 정산 — 고정금액 옵션 (이미 코드 있음, 확인 필요)
- 코드 존재: 개인=유가보조금(원/L, 기본 221) 직접입력 / 법인=경감률(%)↔**회사 고정단가(원/L)** 토글 (`MoreScreen` 603~673행).
- **조치:** v17 설치 후 실기기 확인. 안 보이면 구버전 테스트였던 것. 개인에게도 "고정 원/L"가 명확히 보이게 라벨 점검.

## 4. 일 고정지출 칸 제거 (중복)
- **현상:** "일 고정 지출(식비·세차비 등)" 항목(`MoreScreen` 797행 + 689행 다이얼로그). 잡지출(영수증 OCR)과 중복.
- **조치:** 항목·다이얼로그 삭제 + 홈 순수익 계산에서 `daily_expense` 제거(계산 깨지지 않게). 지출은 잡지출/영수증으로 일원화.

## 5. 근무세션 — 퇴근 요약·기록 (핸들링 앱 값)
- **현상:** 출근은 좋은데 **퇴근하면 남는 게 없음**(그냥 종료). 
- **조치:** 퇴근 시 **근무 요약 카드**: 총 근무시간 · 순근무(일시정지 제외) · 이동거리 · 그 시간대 매출 · **시간당 매출**. + **근무기록 저장**(누적 리스트/통계). prefs만으로도 시작, 서버 누적은 차후.

## 6. 전표→그날 매출 자동적용 (docs/21 본체)
- 전표 스캔 → 확인 다이얼로그(날짜 자동제안 [예]/[아니요]) → **그 날짜에 소계·합계 기록 + 회사전송 동시** + 재스캔 멱등.
- **플로팅↔전표 빈칸만 채우기**: 장소·시간만 있고 금액 빈 운행에 시간매칭으로 금액만, 이미 있으면 확인만(precedence).
- 삼중 교차검증(개별합=소계=총합계).

## 7. 유니버설 매출 임포트 (docs/21)
- 진입 2갈래: 📄파일(엑셀/CSV) · 🖼이미지(스샷). 구조적=무료 규칙, 낯선 앱·**손글씨**=AI 폴백. 최종 하나의 확인 표 → `import/bulk`(멱등, 서버 배포됨).
- 월 캘린더(1번) 그대로 따오기(격자 인식 보강). 하루 상세(2번)도 추출.

## 8. 영업일 시작(dayStart) 전면 적용
- 설정 UI 이미 있음(개인·일차·야간). **현재 홈에만 적용**, 기록·월별·통계·마감 미배선.
- **조치:** 서버 `/api/trips·/api/stats·/api/summary·/api/expenses`에 `dayStart` 추가 + 앱 전 화면 전송.

## 9. 마감 화면 정리
- 오늘/어제/그제 선택기: 전표가 자기 날짜로 들어가면 필수 아님 → 보조(과거 재제출)로 축소. 전표 스캔 시 날짜 자동 세팅.

## 10. 로그인 방식 · 계정 전환 (실사용 이탈 버그) — 레퍼런스 반영
- **현상:** 카카오 **자동로그인 강제** 때문에 기기 변경·로그아웃 후 **다른 아이디로 로그인 막힘**(이전 계정 자동 복귀).
- **핵심 해법(레퍼런스 캡처):** **"자동 로그인 = 체크박스, 기본 해제."** 강제가 아니라 유저 선택 → 체크 안 하면 매번 로그인 화면 → **계정 전환 자유**. 이 한 줄이 버그의 정답.
- **로그인 화면 구성(레퍼런스대로):**
  - 로고 · **이메일 / 비밀번호**(눈 아이콘 show/hide)
  - **☐ 자동 로그인**(기본 해제) · **임시 비밀번호 발급**
  - 소셜: **카카오(기존)** + 구글/네이버(자리) · **게스트/기기 로그인**(카카오 없이 시작 유지)
  - "계정이 없으세요? **회원가입 ≫**" · "로그인에 문제가 있나요? → **계정찾기** · **채팅 문의**(오픈방)"
- **조치:** (a) **완전 로그아웃** = auto-login 플래그 + user_id/토큰 prefs 클리어 → 로그인 화면. (b) **"다른 계정으로 로그인"**(카카오 `prompt=login` 강제 재인증). (c) 기기 바뀌면 페어링(docs/13 v18)으로 같은 계정 이어받기 안내.
- **범위 주의:** 이메일/비번 로그인+회원가입+임시비번은 **서버 인증 신규**(비번 해시·이메일 발송) = 큰 편. → v17은 **자동로그인 체크박스화 + 완전로그아웃 + 계정전환(카카오/게스트)** 먼저, 이메일/비번·소셜확장은 그 다음 덩이.
