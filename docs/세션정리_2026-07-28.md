## 2. 오늘 발견한 핵심 인사이트

- **텔레메트리 "4명"은 오해였음.** 실제 데이터 유저 **21명**, 그중 **13명이 10건+ 단골**, 총 운행 **1,179건**.
- **진짜 문제 = 활성화(첫 운행).** 가입 106명 중 **85명(80%)이 운행 0건**. 반면 첫 운행 넘긴 21명 중 13명(62%)이 단골로 정착 → **유지력은 좋고, 입구에서 샌다.**
- 가입 79명이 7/19 한 주에 몰림(홍보 유입) → 대부분 첫 운행 없이 이탈.
- **원인 가설:** 홍보글이 "버튼만 누르면 자동 기록 / 전표 찍으면 매출 자동"을 강조했는데, 실제는 (1) 플로팅 버튼 권한 설정 마찰, (2) OCR 인식률 낮음, (3) 자동 금액매칭 미출시 → 체감이 수동 → 이탈. (기대 vs 실제 간극)

## 3. 카피앱 방어 전략 (요약)

- **특허**: 개념·UI 아니고 **구체적 방법**(OCR→GPS 금액매칭, 정밀도 계층 수요집계 등)만 보호. 회피설계 가능 → 만능 아님, 억지력. **변리사 상담 필요**(우선심사 등).
- **역설계 방지**: APK는 항상 디컴파일됨. → **핵심 로직을 서버에 유지**(이미 대부분 서버). 난독화(R8)는 보조.
- **함정기술(honeypot)**: 카피 "탐지·증명"용(워터마크/가짜 시드). 보조.
- **진짜 해자**: 코드 아니라 **데이터·커뮤니티·실행 속도** + 네트워크 효과(유저 많을수록 정확해지는 콜 히트맵).
- **권고**: 난독화·풀 인증은 출시 후. 지금은 서버 rate limit(저위험)만.
