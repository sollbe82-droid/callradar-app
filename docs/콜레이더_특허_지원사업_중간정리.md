## A. 특허 현황과 추가할 것

### 이미 확보 (우선일 있음)
- **가출원(임시명세서) 12개 발명** — 무입력 자동수집, 크라우드 수요예측, 세무·정산 자동화, 수락률 지표, 비식별 집계, 안전·건강 개입, 신뢰도 검증, 신용연계, 산업서비스 중개 등.
- 성격: **가출원이라 "우선일"만 확보.** 아래 액션 필수.

### 추가해야 할 발명 (이번 논의에서 도출 — 가출원 이후라 지금은 보호 밖)
- **★ 플래그십: 비배차 기사편 수급 추정** — "운행/플로팅 시작 신호 = 분산 공급 센서" + 접근성 콜 이벤트 = 수요 → 지역·시간대 **경쟁강도** 산출. 배차 데이터 없이, 복수 플랫폼을 가로질러. + **신뢰도 가중 개인→크라우드 핸드오버**(표본수·신뢰구간 내장, "정확이 아니라 예측").
- **C. 서버 규칙 자가치유 파서** — 앱 UI 바뀌면 온디바이스로 규칙 재도출→서버로 전 기사 전파.
- **D. 명함 → 무설치 원터치 예약** — 스캔형 명함이 그 기사 전용 예약페이지를 열고, 설치 없이 날짜·출발·목적지 원터치 → 그 기사 앱으로 푸시 + **양방향 단골 등록** + **예약 QR 박힌 자동 홍보물**.
- E. 이벤트(야구·공연·집회·크루즈) 기반 수요 → 플래그십의 종속항으로 편입.

### 특허 액션 (우선순위)
1. **가출원일로부터 12개월 내 정식 본출원 전환**(청구범위 확정) — 안 하면 소멸. **마감 있음.**
2. 본출원에 **플래그십·C·D 포함** 또는 추가 가출원으로 우선일 확보.
3. 상표 "콜레이더/CallRadar" 등록(견본 보유).
4. FTO: 플래그십은 "배차·매칭·요금을 안 함"으로 좁혀 플랫폼 특허 회피(스크리닝 문서 참조).

## B. 지원사업 (82년생·중장년·무자본·아이디어 단계 매칭)

> 나이 44 → **청년창업(만 39 이하) 트랙은 제외**. 아래는 **연령무관/중장년** 트랙 위주.

### 1순위 — 예비창업패키지 (일반형 · 중장년)
- 자격: **사업자등록 전** 예비창업자, 연령제한 없음(청년/중장년 구분 선발 → 대표님=중장년), 기술·BM 보유(단순 카페·소매 제외 → 우리는 해당).
- 지원: 사업화 자금 + 멘토링. **아이디어~시제품 단계 정석 진입점.**
- 링크: https://www.bizinfo.go.kr/sii/siia/selectSIIA200Detail.do?pblancId=PBLN_000000000119019

### 병행 후보
- **중장년 기술창업센터** (만 40세 이상 예비/3년 이내): 전국 25개 센터 **무료 창업공간(1년+연장) + 사업화 자금 300만~1,000만원**. 단순 서비스·음식·소매 제외(기술창업이어야 함 → 우리 해당).
- **생애최초 창업 지원** (만 40+, 창업경험 없음): 교육·경영안정화. 대표님이 첫 창업이면 해당.
- **넥스토로컬 40+ / 지역상생 중장년 창업** (서울 거주 만 40~64): 창업교육·전문가 멘토링. 서울 거주 시.
- **재도전 성공패키지**: 과거 폐업·재창업자 대상 → 해당 시에만.

### 규제 체크(필수, 지원사업 발표 전)
- 개인 위치·운행정보 취급 → 「위치정보법」 위치기반서비스사업 신고 여부 확인. 애매하면 **ICT 규제샌드박스**.

### 후순위 (정체성 안 맞음 — 앞서 정리)
- KISA 안전 LBS 공모전, 국방벤처: 우리는 "안전 LBS/국방"이 아니라 모빌리티 데이터 플랫폼이라 매칭 낮음.

### 지원서에 그대로 쓸 강점
- 카카오가 구조적으로 못 오는 **중립·비배차 포지션** + 플랫폼도 못 보는 **교차플랫폼 실현수익 데이터 해자**.
- **비배차라 규제 가벼움**(리스크 낮음).
- **특허 가출원 완료**(우선일 확보) — IP 있음.
- **작동하는 앱 + 실사용 검증** 이미 진행 중(단순 아이디어가 아님).
