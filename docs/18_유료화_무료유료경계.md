# 콜레이더 — 유료화: 무료/유료 경계 (결정 기록)
*작성 2026-07-23 · 대표 판단 확정 · 설계헌장 북극성에서 파생 · 유료화 설계 시 이 기준 사수*

> **회사 한 줄: "불편함을 편안함으로 만드는 앱."** (= 북극성 "누가 써도 간편 — 이거 왜 이제 나왔냐")
> 여기서 유료화 기준이 나온다: **유료 기능은 불편을 확 줄여줘야 한다(진통제). 불편을 더하는 건 유료 훅이 못 된다.**

---

## 1. 대원칙 (돈 내는 이유)
- **비타민(있으면 편함) ≠ 진통제(없으면 매일 아픔).** 유료 앵커는 **진통제**여야 한다.
- **불편을 더하면 유료 불가.** 예: 다중 오픈방 순차 붙여넣기는 편의지만 불편이 껴 있어 **단독 유료 상품 안 됨**(번들 곁들이만).
- **브랜드를 퍼뜨리는 기능은 무료.** 공유를 돈 받고 막으면 바이럴이 죽음.

## 2. 유료 앵커 (돈 내는 진짜 이유)
1. **완전 자동 기록·금액 자동입력** — 매일 손으로 넣던 걸 없앰. **우리가 특허 낸 최종 상업적 가치.** 게이트는 여기.
2. **정밀 핫존 예측** — 특허 발명3 그대로: **무료 제보가 예측을 키우고, 정밀 예측은 유료 유저에게.** 많이 모을수록 유료가 좋아짐.
- 곁들이(번들): AI 자유질문(비용 게이트), 세무 패키지, 다중 오픈방. **단독 아님, 앵커에 얹기.**

## 3. 무료 (성장·바이럴 엔진 — 최대한 푼다)
기본 기록·통계·공항정보 · **콜/운행 공유(스샷·문구·오픈방)** · 핫존 보기 · 콜 제보 · 과거기록 임포트 · 라이트모드 · 페어링(다기기 통합). → 유저 늘리고 브랜드 퍼뜨리는 건 전부 무료.

## 4. 경계 요약표
| 구분 | 항목 | 왜 |
|------|------|-----|
| 무료 | 기록·통계·공항·공유·핫존보기·제보·과거임포트·페어링 | 성장·바이럴·브랜드 노출 |
| 유료 | **자동화(기록·금액 자동)** | 진통제 · 특허 핵심 |
| 유료 | **정밀 핫존 예측** | 진통제 · 발명3(무료가 키우고 유료가 씀) |
| 번들 | AI 자유질문·세무 패키지·다중 오픈방 | 앵커에 얹는 곁들이 |

## 5. 게이트 구현 (이중작업 방지)
- 각 유료 기능은 **entitlement 토글**(driver_settings/서버 값) 뒤에.
- **지금(v13~)**: 토글 주인 = 유저(무료로 다 켬). **유료화 후**: 토글 주인 = 서버 구독상태. → **기능 코드 그대로, 게이트 소스만 교체 = 두 번 일 안 함.**

## 6. 검증 (유료 후보 넣을 때마다)
- [ ] 이게 진통제인가(없으면 매일 아픈가)? 비타민이면 무료로.
- [ ] 불편을 **줄이나**? 더하면 유료 훅 탈락.
- [ ] 브랜드 퍼뜨리는 기능을 유료로 막고 있진 않나(바이럴 저해)?
- [ ] 게이트가 토글 하나로 무료↔유료 전환되나(코드 무수정)?
