## 4. 서버 핵심 (영업일 개념이 중요)
- 영업일 = `DATE((started_at KST) - dayStart시간)`. dayStart 기본 0(자정). 야간기사는 값 설정.
- `/api/today/:uid?dayStart=` = **현재 영업일** 매출/콜/최근운행.
- `/api/trips/:uid?date=X&dayStart=` = 영업일 X의 운행(origin_lat/lng, dest_lat/lng 포함). `?month=YYYY-MM` 도 지원.
- 기타: `/api/trips/manual`(운행/제보 저장, raw_ocr), `/api/expenses`, `/api/stats/daily`, `/api/report-hotspots`, `/api/rhythm/:uid`, `/api/demand`(coarse|fine 정밀도), `/api/airport/passengers`(passgrAnncmt), `/api/usage`(+/report, 텔레메트리), `/api/geocode/reverse?x=&y=`(KAKAO_REST_KEY 역지오코딩), `/api/events`, `/api/profile`, `/api/export`(CSV), `/api/health`.

## 9. 클로드(나) 작업 성향 — 새 세션이 일관되게 이어가도록
- TaskCreate/TaskUpdate로 태스크리스트 적극 사용(진행 위젯).
- **다이얼로그 키보드 가림 = 커스텀 `Dialog(DialogProperties(usePlatformDefaultWidth=false))` + `BoxWithConstraints`로 가용높이 재서 스크롤 축소 + 버튼 하단 고정** 패턴으로 해결(확립됨). AlertDialog는 별도 윈도우라 imePadding이 무효 → `decorFitsSystemWindows` 시도도 불완전 → 커스텀 Dialog가 정답.
- 검증: `uiautomator dump`→printnodes.js, `screencap`→Read 이미지. adb input tap/swipe/text.
- 커밋 메시지 = **특수문자·괄호·슬래시 없이 하이픈**으로(cmd/powershell 이스케이프 이슈). 예: `fix-edit-dialog-keyboard`.
- **findstr 한글 깨짐** → 피하고 grep(리눅스)/node로. cmd에서 `&&`는 powershell 래퍼라 `cmd /c "... && ..."`로 감쌀 것.
- adb **콜드스타트 첫 탭 먹힘 / 홈 복귀 리로드 중 탭 먹힘** = 자동화 한정 현상, 실사용 무관. warm 상태에서 재탭. 재부팅으론 안 고쳐짐.
- 빌드 후 서명 불일치(INSTALL_FAILED_UPDATE_INCOMPATIBLE) = 기기엔 릴리스 설치돼 있으니 **릴리스로 빌드**해야 함(디버그 설치 시도 금지).
