# 콜레이더 — 스샷 기반 반자동→완전자동 단계 설계 (v18~) · 결정 박제

*작성 2026-07-25 · 루이 확정. docs/15(심사쪼개기)·17(자동화 감지노트)의 후속·정본 갱신.*

> 한 줄: **플로팅 출발/종료 사이에 스샷으로 플랫폼·출발·목적지·금액을 잡아 반자동화하고, 그 위에 v6 완전자동을 입힌다.** 심사는 docs/15 "쪼개기" 규칙(한 제출=민감권한 1개+선언+시연영상) 그대로.

---

## 1. 확정된 플로우 (루이 안)
출발(플로팅) → **[시작 스샷]** 플랫폼 구분(카카오/티머니/우버) + **출발·목적지 추출**
→ 출발/목적지 텍스트 없으면 **우버**, 아무것도 없으면 **길빵**
→ 운행 → 종료(플로팅) → 종료 전 금액 입력 때 **[종료 스샷]** → **금액 파싱 → 자동 금액 입력**
→ (이후 단계) **v6 완전자동**을 이 위에 입힘.

## 2. 결정: 목적지 처리 = **B안 (시작 스샷 OCR)** ✅
- **A안(기각):** 시작 스샷 생략, 종료 스샷 한 장으로 금액+플랫폼, 목적지는 GPS 도착좌표→역지오코딩(동). (docs/17 §2 "핵심 단순화"가 이쪽이었음)
- **B안(채택):** 시작 스샷도 찍어 **카카오·티머니 목적지 텍스트까지 정확히** 추출.
- **채택 이유(루이):** 이 시작-스샷 인식이 **나중 완전자동 기록의 시작점(씨앗)** — 여기서 플랫폼·출발·목적지를 확실히 잡아두면 자동화 단계에서 그대로 재사용된다. 정확성이 A의 마찰-최소보다 우선.
- **플랫폼별 실측(docs/17 §1-B) 반영:** 카카오T·티머니 ONDA = 목적지 텍스트 → OCR 가능. 우버 = 지도 한 장(텍스트 없음) → "텍스트 없음"을 우버 판별 신호로 사용, 목적지는 GPS 동 보조. 아무 콜앱 신호 없음 = 길빵.

## 3. 분할 승인 매핑 (docs/15 규칙 준수)
1. **v17 (심사중, 권한 0):** 로그인 체크박스·완전로그아웃·계정전환 / 설정 저장·로드 감사 / 수수료 소수점 / 일고정지출 제거 / 근무세션 퇴근요약.
2. **v18 = 캡처 발판 (민감권한 1개: FOREGROUND_SERVICE_MEDIA_PROJECTION):** 유저 개시 **화면 캡처 → 워터마크 → 공유**. MediaProjection 권한을 스토어에 정식 각인. 제출물 = FGS type=mediaProjection 선언 + 인앱 동의화면 + **시연영상(루이)**. 이 라운드 게이트는 이거 하나.
3. **다음 = 종료 스샷 금액 자동입력:** 승인된 권한 위, 종료 화면 스샷→OCR 금액(ReceiptOcr 재사용, 우버 95→100%). "수동 금액입력" 소멸. (docs/17 §2·§4)
4. **다음 = 시작 스샷 플랫폼·출발/목적지 (B안 본체):** 같은 캡처 권한 재사용. 텍스트 없음→우버, 신호 없음→길빵.
5. **다음 = 시작/종료 GPS 자동 (활동인식 권한 1개 추가):** 지오펜스+활동인식으로 플로팅 없이 운행 경계. (docs/15 v16 단계)
6. **최종 = v6 완전자동 입히기 + 유료화(entitlement 토글).** (docs/15 v17 단계)

## 4. 규칙 재확인 (어기면 리젝/밴)
- 민감권한은 **한 제출에 하나만**(v18=캡처, GPS라운드=활동인식). 권한0 기능(갤러리 임포트 등)은 캡처 라운드에 **섞지 말 것**.
- 권한 추가 제출엔 **선언 + 시연영상** 필수.
- **접근성 스크래핑·완전 0터치는 스토어판 금지**(pro/APK만). 스토어판은 항상 "유저 개시"(근무 1회 동의 + 하차 1탭).
- 승인된 동작만 — "통과 후 몰래 켜기" 금지.

## 5. 현재 코드 상태 (착수 전 점검)
- `AndroidManifest.xml`: `FOREGROUND_SERVICE_MEDIA_PROJECTION` **주석 처리(비활성)**. → v18에서 활성.
- `ScreenCaptureService.kt`, `ScreenCapturePermissionActivity.kt` **존재(대기 중)** — 발판 플로우 마무리 대상.
- 금액 OCR = `ReceiptOcr`/`ReceiptOcrService` 재사용(발명2). 우버 특례 보정(isUberFareScreen).
- 기기별 플랫폼 = v12 페어링에 이미 구현(서브폰=우버 박기 가능).

## 6. v18 착수 시 할 일
1. 매니페스트 권한·FGS type=mediaProjection 활성화.
2. 유저 개시 캡처→워터마크→공유 플로우 마무리(ScreenCaptureService/PermissionActivity).
3. 인앱 동의화면("스샷 찍을 때만 사용, 그 외 화면 안 봄") 명시.
4. Play 데이터 선언 문구 초안.
5. **루이:** 시연영상 촬영 + Play 업로드.
