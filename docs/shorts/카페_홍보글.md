# 홍보글 — 2026-09-05 기준 (구글플레이 자동기록 개통)

> **지금의 뉴스는 "현직 기사가 만들었다"가 아니다.** 그건 이미 여러 번 썼다.
> **"구글플레이에서도 자동기록이 된다"** — 이게 헤드라인이다.
>
> 특히 **플레이로 깔았다가 매번 손으로 눌러야 해서 포기한 기사들**이 타깃이다.
> 그분들은 앱이 나빠서 나간 게 아니라 **자동기록이 없어서** 나갔다. 이제 그 이유가 사라졌다.

**현재 상태 (2026-09-05)**
```
구글플레이  v3.0.0 프로덕션 배포 (9/2) · 접근성 자동기록 포함 · 128명 대상
원스토어    v3.0.1 배포 중 · 같은 기능
승인일      9/1 — 접근성 포함 빌드가 구글 심사를 통과한 최초
```

## ① 택시 카페용 (네이버/다음)

```
구글플레이에서도 택시앱 자동기록 됩니다 (콜레이더)
플레이스토어 자동기록 드디어 열렸습니다 — 예전에 포기하신 분들 보세요
[콜레이더] 구글 심사 통과했습니다. 이제 플레이에서도 자동으로 기록됩니다

**본문**
```
안녕하세요. 콜레이더 만드는 현직 법인택시 기사입니다.

전에 플레이스토어로 깔았다가 그냥 지우신 분들 계실 겁니다.
운행할 때마다 시작·완료를 손으로 눌러야 했으니까요.
하루 15~20콜 뛰면서 매번 그걸 누르는 건 저부터가 못 하겠더군요.

그게 앱이 못 만들어서가 아니라, 구글 정책 때문이었습니다.
택시앱 화면을 읽으려면 접근성 권한이 필요한데
그동안 심사에서 계속 막혀서 원스토어에서만 자동기록이 됐습니다.

이번에 구글 심사를 통과했습니다.
이제 플레이스토어에서도 자동으로 기록됩니다.

■ 뭐가 달라지냐

카카오T · 우버 · 티머니GO 화면을 읽어서
손님 태우고 내리는 걸 앱이 알아서 기록합니다.
출발지, 도착지, 요금까지 남습니다. 버튼 안 누르셔도 됩니다.

그래서 퇴근할 때 오늘 몇 콜에 얼마 벌었는지가 그냥 나와 있습니다.
사납금이랑 가스값 빼고 실제로 얼마 남았는지도요.

■ 켜는 법

설치하고 앱을 열면 안내 화면이 뜹니다.
거기서 '접근성' 하나만 켜 주시면 됩니다.
안드로이드 보안 때문에 마지막 스위치는 사용자가 직접 눌러야 합니다. 제가 대신 못 켭니다.

삼성폰이면 '제한된 설정 허용'을 먼저 눌러야 접근성이 켜지는 경우가 있습니다.
그것도 앱 안내에 순서대로 나옵니다.

■ 미리 말씀드릴 것

- 읽기만 합니다. 화면을 캡처하지도, 대신 눌러주지도 않습니다.
- 위 3개 택시앱 외의 화면은 읽지 않습니다. 앱에 그 목록이 박혀 있어서 기술적으로 안 됩니다.
- 자동기록이 싫으면 안 켜도 됩니다. 그래도 나머지 기능(수동 기록·정산·통계)은 다 씁니다.
- 아직 쓰는 분이 200명 조금 넘습니다. 완성된 앱이 아닙니다.
- 버그 제보 주시면 대부분 그 주에 고칩니다. 제가 매일 쓰는 앱이라 저도 급합니다.

■ 설치

· 자동기록이 꺼져도 앱은 '켜짐'이라고 표시하던 문제

## 하지 말 것

- **여러 카페 도배** — 자동 차단이고 계정이 막힌다
- **"1위·최고·완벽"** — 리뷰 1개짜리 앱이 쓰면 역효과
- **접근성을 대충 설명하기** — 기사들은 권한에 민감하다.
  "읽기만 한다 / 3개 앱만 / 캡처 안 한다 / 안 켜도 된다" 를 반드시 같이 쓴다.
  이걸 빼면 "왜 내 화면을 보냐"는 댓글 하나로 글 전체가 죽는다.
