# 쇼츠 녹화 방법 — 안 짤리게 · 음악 맞춰서

## 왜 지난번에 잘렸나

무대를 **1080×1920 픽셀로 고정**해 놓고 PC 화면(16:9)에 띄웠다.
그러면 좌우에 검은 여백이 생기고, 그 상태로 녹화하면 **16:9 영상 한가운데 세로 영상**이 박힌다.
쇼츠에 올리면 다시 잘린다.

이번엔 무대를 픽셀이 아니라 **화면에 맞춰** 만들었다(`min(100vw, 100vh*9/16)`).
**폰에서 열면 화면을 꽉 채운다** → 그대로 녹화하면 진짜 9:16 이다.

---

## ★ 가장 쉬운 방법 — 폰으로 녹화 (권장)

1. `promo_30s.html` 을 폰으로 보낸다 (카톡 '나에게 보내기' 또는 USB)
2. 폰에서 파일을 열면 브라우저(크롬/삼성인터넷)에서 재생된다
3. 브라우저 **전체화면**(주소창 숨기기 — 아래로 스크롤하면 숨는다)
4. **녹화 모드** 버튼을 누른다 → 하단 버튼이 사라지고 처음부터 재생
5. 폰 **화면 녹화** 시작 → 30초 뒤 종료

이러면 **크롭이 필요 없다.** 폰 화면 비율 그대로 9:16 이다.

## PC 로 녹화할 경우

`Win + G`(게임바) 로 녹화하면 16:9 로 찍힌다 → **편집에서 세로로 잘라내야 한다.**
자를 때 무대(중앙 세로 영역)만 남기면 된다. 번거로우니 폰 쪽을 권한다.

## 음악

**직접 만들 수 없어서 소스만 안내한다.**

**유튜브 오디오 보관함**(studio.youtube.com → 오디오 보관함)이 가장 안전하다.
저작권 클레임이 안 붙고, 쇼츠 수익화에도 문제가 없다.

- 분위기: **Upbeat / Inspirational / Corporate** 계열, 보컬 없는 것
- 템포: **120 BPM 근처** — 이 영상의 장면 전환이 **120BPM 마디(2초)에 맞춰져** 있다.
  120BPM 곡을 깔면 컷이 박자에 저절로 맞는다.
- 길이: 30초. 곡 앞부분보다 **드럼이 들어온 지점부터** 쓰는 게 낫다.

**장면 전환 시점 (마디 경계)**
```
0초    훅        "오늘 하루 끝났는데 / 얼마 벌었지?"
4초    문제      수첩 · 플랫폼 정산 · 가스/사납금
10초   해결      저절로 쌓입니다 → 매출·순수익·시간당
18초   인사이트   언제 나가야 잘 버는지 → 20~0시
24초   마무리     현직 기사가 만든 앱 · 콜레이더
30초   끝
```
음악의 **큰 전환(드롭·후렴)** 을 10초 또는 18초에 맞추면 가장 잘 붙는다.
