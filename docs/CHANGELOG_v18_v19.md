# 콜레이더 업데이트 내용 정리 (v18 · v19)

작성: 2026-07-26

---

## v18 (versionName 1.8) — 화면 캡처·공유

### Play 업데이트 내용(짧게)
- 운행 화면을 캡처해 워터마크와 함께 카톡 등으로 공유하는 기능이 추가됐습니다.

### 상세 변경
- **📸 화면 스샷 공유**: 플로팅/더보기에서 현재 화면을 캡처 → 워터마크 삽입 → 카카오톡 등으로 공유.
- 화면 캡처 권한(MediaProjection) 및 포그라운드 서비스 선언 추가(Play 정책 대응).
- 캡처 전 **인앱 동의 화면** 추가(무엇을·왜 캡처하는지 안내).
- 심의를 위해 "권한 1개씩 쪼개서" 제출하는 전략의 첫 단계(캡처 발판).

## v19 (versionName 1.9) — 정산·급여·가져오기 대개편 + 테스터 피드백

### Play 업데이트 내용(짧게)
- 급여명세서 사진으로 공제 항목 자동 입력, 마감 영수증·타 가계부앱 화면 가져오기(자동 인식), 사납금 완납 시 순수익 자동 반영 등 정산 기능이 크게 좋아졌습니다.
- 뒤로가기·로그인 유지·내보내기·라이트모드 등 사용성 버그를 다수 고쳤습니다.

### 1) 급여·정산
- **급여 공제(명세서 기준)** 신설: 기사 설정에 기본급·4대보험·조합비·기타공제를 입력하면 홈 "예상 월급 수령액"에 반영.
- **급여명세서 사진 자동 채우기(OCR)**: 명세서를 촬영/선택하면 항목이 자동 입력(좌표 기반이라 2단 표도 인식). 서버 전송 없이 기기에서만 분석.
- **실급여 0 체크박스**: 사납금 낮고 가스 기사부담 등으로 기본급이 명목상인 도급 기사용. 체크 시 명세서를 실수령에 더하지 않고 도급 초과수익만 반영.
- **사납금 완납 반영**: 이번 달 고정 사납금을 다 채우면(정산일수 초과 근무 또는 총매출 ≥ 총사납금) 오늘 순수익에서 사납금을 빼지 않고 지출비만 반영. "(사납금 완납)" 표기.
- **월급 실근무일 계산**: 실제 매출 있는 날 기준으로 사납금·가스 차감(월초 과다 마이너스 방지).
- 수수료 **소수점**(예: 3.3%) 지원.

### 2) 가져오기(과거 실적 마이그레이션)
- **가져오기 메뉴**: 📷카메라 / 🖼갤러리 / 📄파일(CSV) + 확인·수정 표 + 직접 추가.
- **마감 전표 인식**: 티머니고/카카오 등 일 마감 영수증의 총합계를 그날 수입으로 인식(총합계가 흐리게 찍혀도 금액 최댓값으로 처리).
- **타 앱 화면 인식**: 가계부 앱의 일간 요약(총수입/순수익)·월 달력(요일·날짜별 수입/지출)도 자동 표로 변환.
- **회전 자동 보정**: 옆으로/거꾸로 찍은 사진도 4방향 중 가장 잘 읽히는 방향을 자동 선택.
- **파싱 규칙 서버 다운로드**: 인식 규칙을 서버에서 받아 적용 → 안 잡히는 새 양식이 나와도 앱 업데이트 없이 서버만 갱신하면 전 유저 즉시 개선(유저 데이터 수집 없음).

### 3) 기록·통계
- **달력 날짜별 수입/지출/순수익**: 월별 달력에서 날짜를 누르면 그날 수입·지출·순수익을 함께 표시.
- **영업일 시작(dayStart) 전면 적용**: 야간·일차 기사의 자정 넘김 운행이 올바른 영업일로 묶임(데이터 짤림 해결).
- **내보내기(CSV)** 정상화(이전 404 오류 수정).

### 4) 버그 수정·사용성
- **뒤로가기**: 홈이 아닌 탭에서 뒤로가기는 홈으로(앱이 갑자기 종료되던 문제 수정), 홈에서 뒤로가기만 종료.
- **업데이트 후 로그인 유지**: 자동 로그인 기본 켜짐 → 업데이트해도 로그인 풀리지 않음.
- **영수증/마감 저장 폴백**: OCR이 실패해도 표에서 직접 넣어 저장 가능(기록 누락 방지). 서버 저장 버그도 수정.
- **라이트 모드**: 더보기 타일 글자 짤림 수정, 랭킹 닉네임 글자색 보정(밝은 배경에서 안 보이던 문제).
- **키보드**: 입력창이 키보드에 가리지 않도록 스크롤 처리, 화면을 누르면 키보드 닫힘.
- **플로팅 버튼**: 오작동 방지로 길게 누르기 0.6→1초, 이동 감지 10→28px(덜 민감하게).
- **홈 화면 재구성**: 상단에 ⚙️기사 설정 버튼, 하단에 "콜레이더 기사 톡방" 배너, 앱 버전 표기, 종료 버튼 제거, 중복 기능 정리.
- 설정 값이 **업데이트해도 유지**되도록 저장/로드 정비.

## 참고
- v18은 화면 캡처 심의 라운드, v19는 정산·가져오기 대개편 + 테스터 피드백 반영본.
- 파싱 규칙·정산 계산은 모두 기기 또는 서버→앱 단방향으로 동작하며 개인 데이터를 수집하지 않음.
