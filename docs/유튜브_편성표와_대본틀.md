# 콜레이더 채널 — 편성표와 대본 틀

> 2026-09-07 · 채널 `콜레이더` @callradar (구 카니발, 구독 5명 승계)

---

## 1. 쇼츠만? 롱폼도? — 둘 다 합니다. 다만 역할이 다릅니다

대표 판단이 맞습니다. **하나만 하면 반드시 막힙니다.**

| | 쇼츠 | 롱폼 |
|---|---|---|
| 하는 일 | **모르는 사람에게 닿는다** | **닿은 사람을 붙잡는다** |
| 알고리즘 | 구독 안 해도 계속 밀어줌 | 구독자·검색 위주 |
| 약점 | 봐도 구독으로 잘 안 감. 채널을 기억 못 함 | 처음 보는 사람에게 안 닿음 |
| 수익화 | 조회수 대비 단가가 매우 낮음 | 시청시간 4,000시간 조건을 여기서 채움 |

쇼츠만 하면 조회수는 나오는데 **구독자가 안 늘고 채널이 안 남습니다.**
롱폼만 하면 **아무도 발견을 못 합니다.**

### 제작비는 안 늘어납니다 — 한 번 만들어 세 번 씁니다

```
롱폼 1편 (6분)  →  쇼츠 3편으로 자름  →  커뮤니티 글 1개
   주간 리포트        가장 센 구간 3개        투표 한 줄
```

그래서 **롱폼 주 1편 + 쇼츠 주 6편**을 하나의 취재로 만듭니다.
새로 만드는 건 쇼츠 3~4편뿐입니다.

## 2. 주간 편성표

```
월  쇼츠  오늘 밤 브리핑          (야구 파장 · 공항 · 행사)
화  쇼츠  숫자 하나               (어제 데이터에서 뽑은 사실 한 개)
수  쇼츠  기사 제보               (댓글·톡방 질문에 데이터로 답)
목  쇼츠  이 시간 이 자리         (특정 시간·지역 실측)
금  쇼츠  오늘 밤 브리핑          (주말 전날이라 수요가 제일 큼)
토  롱폼  주간 리포트 5~8분        ← 이번 주 어디가 벌렸나
일  쉼                            ← 사람은 매일 안 올립니다
```

**요일에 포맷을 못 박지 않습니다.** 그날 데이터가 무엇을 주느냐로 정합니다.
불꽃축제가 있으면 화요일이라도 브리핑으로 갑니다. **그게 자동이 아닌 것처럼 보이는 핵심입니다.**

## 3. 쇼츠 포맷 6종 — 각각 대본 틀

모든 쇼츠는 **45~60초 · 세로 1080x1920 · 첫 3초에 숫자 하나**로 시작합니다.
첫 3초에 숫자가 없으면 넘어갑니다. 인사말·채널 소개로 시작하면 그 자리에서 이탈합니다.

---

### ① 오늘 밤 브리핑

> 가장 많이 쓸 포맷. 데이터가 매일 다르니 대본도 매일 다릅니다.

```
[0-3초]   인천공항 택시 대기, 지금 143대입니다.
[3-10초]  지금 출발하면 도착이 한 시간 뒤,
          그때도 백 대 넘게 서 있습니다. 오늘 공항은 아닙니다.
[10-25초] 대신 잠실입니다. 오늘 두산 경기, 예상 종료 아홉 시 사십 분.
          파장 전에 도착하려면 아홉 시 십 분에는 출발하셔야 합니다.
[25-40초] 하나 더. 킨텍스 케이팝 어워즈가 열 시에 끝납니다.
          일산 쪽에 계시면 이쪽이 더 가깝습니다.
[40-50초] 어제 이 시간, 기사분들 평균 시간당 이만 칠천육백 원 버셨습니다.
[50-55초] 콜레이더 데이터 기준으로 매일 저녁 정리해 드립니다.
```

**변주 장치**: 그날 가장 센 항목이 첫 3초로 올라옵니다.
공항이 한산하면 `인천공항 지금 열두 대입니다. 오늘은 갈 만합니다.` 로 시작이 뒤집힙니다.

          토요일 아침 첫 비행기 시간대에 몰렸습니다.

          인천은 두 시간인데 김포는 사십 분이면 돌아옵니다.
          같은 공항 손님이어도 회전이 세 배입니다.
[40-50초] 토요일 새벽에 강서 쪽에 계신다면 이건 기억해 두실 만합니다.

### ③ 기사 제보

> **채널을 사람 채널로 만드는 포맷.** 댓글·톡방 질문을 그대로 읽고 데이터로 답합니다.

```
[0-3초]   "심야 할증 시간에 진짜 더 벌리나요?" 라는 질문 받았습니다.
[3-10초]  숫자로 보겠습니다.
[10-30초] 밤 열한 시부터 두 시까지가 할증 사십 퍼센트입니다.
          기사분들 실제 기록으로는 이 시간대 시간당 삼만 이천 원.
          낮 시간대가 이만 사천 원이니까 삼십 퍼센트 정도 높습니다.
[30-45초] 할증은 사십 퍼센트인데 왜 삼십 퍼센트만 오르냐,
          이 시간엔 빈 차로 도는 시간이 더 길어서입니다.
[45-55초] 질문 있으시면 댓글 주세요. 데이터로 확인해서 답해 드립니다.
```

> 마지막 한 줄이 **다음 회차 소재를 자동으로 만듭니다.** 소재 고갈이 없어집니다.

## 4. 롱폼 포맷 4종

| 포맷 | 주기 | 내용 |
|---|---|---|
| **주간 리포트** | 매주 토 | 이번 주 시간대·지역·플랫폼별 실적. 다음 주 행사 예고로 마무리 |
| **해부** | 월 1~2회 | 하나를 끝까지 판다. "인천공항, 진짜 가도 되나" "심야할증의 진실" |
| **대표의 하루** | 월 1회 | 실제 운행 브이로그. **대표 목소리·얼굴 없이 손과 화면만으로도 됩니다** |
| **앱 이야기** | 새 기능 나올 때만 | 기능 소개. 자주 하면 광고 채널이 됩니다 — **월 1회를 넘기지 않습니다** |

> **'대표의 하루'가 채널의 척추입니다.** 나머지가 전부 자동이어도
> 이 한 편이 있으면 채널 전체가 사람 채널로 읽힙니다.
> 얼굴 없이 대시보드·미터기·창밖·손만 찍어도 충분합니다.

### 제목
그날 **가장 센 숫자**를 앞에 놓습니다. 형식을 정하지 않습니다.

```

       어제 서울 1등 목적지가 김포공항이었던 이유
       심야할증 40%인데 매출은 30%만 오르는 이유

나쁨   콜레이더 오늘의 브리핑 #23        ← 번호는 자동 티의 1순위
       택시 기사 필수 정보!! 꼭 보세요   ← 숫자가 없어 넘어갑니다
```

### 썸네일 4틀
```
공항형   남색 + 대기 대수 큰 숫자 + 비행기 실루엣
행사형   야구장/공연장 사진 + 파장 시각
매출형   막대그래프 + 금액
경고형   빨간 대각선 띠 + "가지 마세요"
```
**그날 내용 종류로 고릅니다. 순서대로 돌리지 않습니다.**

## 6. 소재가 떨어지지 않는 이유

```
데이터    매일 새로 들어옴 (운행·공항·야구·행사)  →  ① ② ④ ⑤ 무한
질문      댓글·톡방에서 옴                        →  ③ 무한
예외      이상값 검사에서 계속 나옴                →  ⑥
```

**③ 이 핵심입니다.** 매 편 끝에 "질문 주세요" 를 붙이면
시청자가 다음 편 소재를 만들어 줍니다. 이건 자동화로 못 만드는 자산입니다.
