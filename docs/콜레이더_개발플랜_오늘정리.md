# 콜레이더 개발 플랜 — 오늘(2026-07-27) 논의 정리

원칙: 겉은 단순·속은 강력 / 어르신도 쉽게, 3040은 "다 되는데 명료" / **각 슬라이스: 빌드 → 온디바이스 사람 검증 → 커밋** (API 검증만으로 끝내지 않음).

## 정보구조 (5화면 확정)
- **홈**: 오늘 순수익(크게) + 공식데이터 카드(공항·이벤트, Tier0) + "AI 비서 준비 중 D-nn"(게이트) + 빠른버튼 4개.
- **기록**: 서브탭 **내역 / 달력 / 월급**. (운행+지출 합쳐 "내역", 제보는 기록에서 빼서 행동버튼으로.)
- **공항**: 도착예정 / 혼잡도 / 택시대기 / 회화.
- **더보기**: 오늘 할 일(미터기·명함) · 이벤트/정보(온오프) · 급여/정산 · 홍보 · 설정/계정.
- 홈 커스터마이즈: 완전 자유 ❌ → **빠른버튼 2개 선택 + 추천카드 온오프**(제한형).

## 빌드 순서 (슬라이스, 각 끝에 온디바이스 검증)
1. **지역설정 + 이벤트 UI + Tier0 공식데이터 카드**  ← 서버 이벤트 API 완료, 다음 착수
   - 운행지역 설정(전국) → 이벤트/공항/추천 지역 필터.
   - 더보기 '이벤트/정보' 카테고리 온오프(야구·공연·집회·스포츠·크루즈·지역행사).
   - 홈에 켠 이벤트 + 공항 실시간을 "수요 정보" 사실 카드로.
2. **기록 탭 재편**: 내역/달력/월급 3서브탭. **예상 월급을 홈→기록으로 이동**. 월급탭에 [회사 명세서 적용]·[역산 계산 설정] 버튼 연계.
3. **명함 → 무설치 예약**: 기사 예약페이지(웹, 설치 없이 원터치 날짜·출발·목적지) → 그 기사 앱 푸시 + 양방향 단골 등록 + **단골(승객) 기록 카드(CRM)**. [서버: 예약/단골 테이블]
4. **원탭 홍보**: 담백한 1인칭 문구 자동생성(편집 가능, AI 티 안 나게) + 예약 QR 박힌 홍보 이미지 + **공유시트 원탭**(카톡·인스타·당근·카페). SNS 자동게시 연동 ❌(막힘).
5. **AI 비서 게이트**: 껍데기 + "데이터 수집 D-nn". 개인 데이터 차면(예: 30일/운행 N건) Claude API로 개인 추천 활성화. 이후 크라우드(공급센서)로 확장.

## 이벤트 데이터 소스
- **공연·콘서트**: KOPIS(공연예술통합전산망) 공개 API — **신청 권장**(공항 API처럼).
- **스포츠**: KBO 등 일정.
- **크루즈 입항**: 인천항만공사/해수부 항만 입출항 데이터.
- **집회·티켓판매소**: 공개 API 없음 → 관리자 등록/뉴스 기반.
- 구조: 공식 API 자동 + 관리자 등록 하이브리드(서버 events 테이블 이미 있음).

## 보류(오늘 결정)
- 미터기 심야할증 지역값: 유저 피드백/생각날 때. (지역 30% 미확인 — 지어내지 않음.)
- 중개·해외 인바운드 예약 마켓플레이스: 장기 별도사업(규제·양면시장) — 지금 아님. 대신 '명함 직접 예약'으로 대체.

- 슬라이스 3(명함 예약)·5(공급센서)는 **본출원 플래그십/추가출원 대상** → 개발 = 실시예 증거.
- 기능 추가 시 3단계 게이트(특허성·FTO) 코멘트 부착(개발헌장).
