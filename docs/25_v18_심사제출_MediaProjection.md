# 콜레이더 v18 — Play 심사 제출 가이드 (MediaProjection 화면캡처 발판)

*작성 2026-07-25 · docs/15(쪼개기)·24(스샷 단계설계)의 실제 제출 라운드. 목표 = 승인.*

> v18 = 민감권한 **딱 1개**(FOREGROUND_SERVICE_MEDIA_PROJECTION) 추가 라운드. 기능 = **유저가 버튼 눌러 화면 1장 캡처 → 콜레이더 워터마크 → 공유**. 백그라운드 상시감시 아님. 다음 자동화(금액 캡처)의 발판.

---

## 0. ★제출 순서 (중요)
- **v17(권한0, 현재 심사중)이 먼저 승인된 뒤 v18을 올린다.** 쪼개기 전략의 핵심 — 안전 버전으로 평판을 쌓고, 민감권한은 그다음 단독 라운드. v17 심사중에 v18로 덮어쓰면 스테이징 이점이 사라짐.
- 트랙 = **비공개(closed) 테스트**. 같은 트랙에 v17 승인 후 v18 새 릴리스로 올림.

## 1. 앱에 이미 반영된 것 (코드/매니페스트)
- `AndroidManifest.xml`: `FOREGROUND_SERVICE_MEDIA_PROJECTION` 권한 선언. `ScreenCaptureService`(`foregroundServiceType="mediaProjection"`), `ScreenCapturePermissionActivity`, FileProvider(`${applicationId}.fileprovider`, `@xml/file_paths`의 `shares/`) 선언.
- **사전 고지(prominent disclosure) 다이얼로그**: 더보기 → "오늘 할 일" → **📸 화면 스샷 공유** 탭 시, 캡처 전에 용도·범위를 명시("버튼 누른 그 순간 1장만 / 백그라운드 관찰·저장 안 함 / 공유 후 미보관")하고, 확인 눌러야 시스템 화면공유 동의창이 뜸.
- 캡처는 **1프레임 즉시 종료**(상시 미러링/녹화 아님). 워터마크 후 공유 시트 → 서비스 자동 종료.

## 2. Play Console — 포그라운드 서비스 권한 선언 폼 (앱 콘텐츠 → 포그라운드 서비스 권한)
- **사용 중인 FGS 유형:** 미디어 프로젝션(Media projection).
- **핵심 기능 설명(붙여넣기용):**
  > 사용자가 앱 내 '화면 스샷 공유' 버튼을 직접 누르면, 그 순간의 화면 한 장을 캡처해 앱 워터마크를 넣어 다른 앱(메신저 등)으로 공유합니다. 택시 기사들이 콜/공항 정보를 커뮤니티에 스크린샷으로 공유하는 사용 흐름을 지원하기 위한 기능입니다. 캡처는 사용자가 버튼을 누른 순간의 1장에 한하며, 백그라운드에서 화면을 지속 관찰하거나 녹화·저장하지 않습니다. 캡처 이미지는 공유가 끝나면 앱에 남기지 않습니다.
- **왜 이 유형이 적절한가:** 화면 콘텐츠 캡처는 MediaProjection API로만 가능하며, 캡처 중 포그라운드 서비스가 요구됨. 사용자 개시·포그라운드·결과 즉시 표시로 정책 범위 내.
- **대체 API 불가 사유:** 다른 앱 화면을 이미지로 만드는 것은 스크린샷 공유 목적상 MediaProjection 외 대안 없음.
- **시연영상 링크:** (아래 3번으로 촬영 후 유튜브 '미등록'으로 올리고 URL 기입)

## 3. 시연영상 대본 (루이 촬영 · 30~60초, 유튜브 미등록)
1. 앱 실행 → 더보기 → "오늘 할 일"의 **📸 화면 스샷 공유** 탭.
2. **사전 고지 다이얼로그**가 뜨는 장면(문구 보이게 2초).
3. "캡처해서 공유" 탭 → **안드로이드 시스템 화면공유 동의창**이 뜨고 "지금 시작" 누르는 장면.
4. 잠깐 뒤 **공유 시트**가 뜨고, 워터마크 박힌 캡처 이미지가 첨부돼 공유되는 장면.
5. 공유 후 앱이 화면을 더 캡처하지 않고 종료되는 것(알림 사라짐) 보여주기.
- 나레이션/자막 한 줄: "유저가 버튼을 누른 그 순간의 화면 1장만 캡처해 공유합니다."

## 4. 데이터 안전(Data safety) 섹션
- **수집/공유 데이터:** 화면 캡처 이미지는 **사용자가 선택한 앱으로 직접 공유**될 뿐, **콜레이더 서버로 전송·수집하지 않음** → "앱이 데이터를 수집" 아님(단, 사용자가 공유 대상 앱으로 보내는 것은 사용자 행위). 데이터 안전 폼에서 스크린샷을 서버 수집 항목으로 넣지 말 것.
- **기기 내 처리:** 캡처·워터마크는 온디바이스, 캐시(`shares/`)에 임시 저장 후 공유 종료 시 미보관.

## 5. 개인정보처리방침 추가 문구 (웹/Console 링크에 반영)
> 화면 공유 기능: 이용자가 '화면 스샷 공유'를 실행한 경우에 한해, 실행 시점의 화면 1장을 캡처하여 이용자가 선택한 앱으로 공유합니다. 본 기능은 이용자의 명시적 실행에만 동작하며, 백그라운드에서 화면을 지속적으로 수집하지 않습니다. 캡처 이미지는 서버로 전송·저장되지 않습니다.

## 6. 리뷰어 노트(선택, 리뷰 메모란)
> Media projection is used ONLY for a user-initiated "share a screenshot" action. Tapping the in-app button shows a disclosure dialog, then the system screen-capture consent. We capture a single frame, add a watermark, and open the share sheet, then stop the service. No background/continuous capture. Feature path: More → 오늘 할 일 → 📸 화면 스샷 공유.
