## 0. 먼저 알아야 할 것 — 이 방식의 유일한 큰 변수

구글은 **감사(audit)를 안 받은 API 프로젝트로 올린 영상을 비공개로 잠그는** 정책이 있습니다.
잠기면 스튜디오에서도 공개로 못 바꿉니다.

**우리 계획은 원래도 "2주간 비공개 업로드 → 대표 확인 후 공개"** 였으니 당장은 문제가 없습니다.
다만 그 뒤 자동 공개로 넘어가려면 잠금 여부를 알아야 합니다.

```
1일차   테스트로 1편 올려 본다
        → 스튜디오에서 '공개'로 바꿔진다  → 잠금 없음. 그대로 간다
        → '잠김' 표시가 뜬다              → 감사 신청서를 낸다(무료, 며칠 소요)
```

**이걸 첫날에 확인하고 넘어갑니다.** 나중에 알면 몇 주를 날립니다.

## 2. YouTube Data API v3 켜기

```
왼쪽 메뉴 → API 및 서비스 → 라이브러리
→ "YouTube Data API v3" 검색 → 사용(Enable)
```

## 3. OAuth 동의 화면

```
API 및 서비스 → OAuth 동의 화면
  User Type    외부(External)          ← 개인 계정은 내부를 못 고릅니다
  앱 이름       콜레이더 업로더
  사용자 지원 이메일   sollbe82@gmail.com
  개발자 연락처       sollbe82@gmail.com
→ 저장 후 계속

범위(Scopes)  → "범위 추가 또는 삭제"
  .../auth/youtube.upload      ← 이거 하나면 됩니다
→ 저장
```

### ★★ 여기가 제일 중요합니다 — 반드시 '게시' 하세요

동의 화면 상태가 **"테스트"** 로 남아 있으면 **인증 토큰이 7일마다 만료됩니다.**
그러면 매주 다시 로그인해야 하고, 자동화가 매주 죽습니다.

```
OAuth 동의 화면 → 게시 상태 → [앱 게시] 클릭 → 프로덕션으로 전환
```

미검증 상태라 로그인할 때 **"이 앱은 확인되지 않았습니다"** 경고가 뜹니다.
`고급` → `콜레이더 업로더(안전하지 않음)으로 이동` 을 누르시면 됩니다.
**본인이 만든 앱을 본인 계정에 쓰는 것이라 정상입니다.**
