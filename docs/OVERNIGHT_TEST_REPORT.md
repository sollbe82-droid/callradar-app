# 밤샘 자동 테스트 보고서 (아침용)

실행: 2026-07-26 밤 · 테스트 계정 user 205(서브폰 게스트)

## 무엇을 했나
"직접 추가 입력 · 상황별 입력을 하나하나" 요청대로, **운행 추가·지출 추가와 동일한 실제 경로**
(`/api/trips/manual`, `/api/expenses`)로 **6월 한 달치 상황별 데이터**를 자동 입력하고 집계를 검증했습니다.
(7월은 이미 스트레스 데이터가 있어 6월을 클린 검증 대상으로 사용)

### 입력한 상황(다양성)
- 운행 **129건** (하루 3~7건, 주1회 휴무 26일)
- 플랫폼 섞기: 카카오T·우버·티머니고·길빵/예약
- 결제 섞기: 카드·현금·자동
- 금액: 4,000~45,000 + 극단값(0·3,500·150,000·999,999)
- **야간 28건**(22·23·0·1·2시) — 자정 경계/영업일 테스트
- 팁 일부 포함
- 지출: **LPG 매일**(리터·단가) + 식비/세차/주차 랜덤

## 검증 결과 — 이상 없음 ✅
| 항목 | 결과 |
|---|---|
| 운행 입력 성공 | 129/129 (실패 0) |
| 6월 집계 일수 | 26일 |
| **중복 행** | **0** (이전 서버 중복 버그 재발 없음) |
| **카드+현금 = 총매출** | **전(全) 날짜 일치** (불일치 0) |
| 총매출/카드/현금/지출 | 8,333,137 / 7,221,769 / 1,111,368 / 1,205,552 |
| dayStart=17(야간) 재분류 | 26 → 29행 (자정 넘김 정상 반영) |
| 지출요약 | LPG 1,082,616원·1,032L, 개인 122,936 (정확) |

→ **데이터 입력 경로 + 집계 로직(월별 카드/현금/지출, dayStart 영업일, 지출요약)은 정상.**
   특히 이전에 잡았던 "저장 안 됨(오늘 필터+dayStart)" / "일별통계 중복" 버그는 재발하지 않음.

## 사람 손이 필요한 항목 (제가 자동으론 검증 불가)
아래는 실기기에서 루이님이 직접 봐주셔야 합니다(코드는 반영·빌드됨):
- **요금 미터기 실주행** — 실제 차로 이동해야 GPS 거리·시간요금 정확도 확인.
- **플로팅 미터기 오버레이** — 더보기→요금 미터기→"플로팅 실행" 후 내비 위에 요금 뜨는지, 탭=저장/길게=취소.
- **명함 QR** — 다른 폰 카메라로 스캔 시 연락처 저장 팝업(전화번호 넣고).
- **월별/달력 UI** — 카드/현금/지출·셀 지출·날짜상세 카드현금이 화면에 예쁘게 뜨는지(백엔드 수치는 검증됨).
- **공항 탭** — 새로고침 시 실시간 데이터·도착예정(여객예고 미래시간대는 data.go.kr 활용신청 후).
