# 콜레이더 — 유저 개선요청 분석 + 운행세션 미터(핸들링 스타일) + 토글 원칙
*작성 2026-07-23 · 테스터 1명이 준 4개 요청 정리 · 설계헌장 통과 · 전부 권한 0(무심사)*

> 대원칙(유저 지시): **모든 기능은 설정에서 사용/미사용 토글.** 신규 기능도, 기존 기능도.

## 0. 인프라 먼저 — "기능 설정"(토글 모음) = 등록소 Step1
- 더보기에 **기능 on/off 토글 섹션**. 앞으로 모든 기능이 여기 얹힘(신규+기존).
- prefs/서버 값 하나로 켬/끔 → 유료화 때 게이트 소스만 교체(docs/18, 이중작업 0).

## 1. 라이트모드 달력 가독성 (쉬움·빠른 win)
- 증상: 라이트모드에서 날짜 숫자와 배경 구분 어려움.
- 해결: CalendarView **셀 격자 줄 + 날짜 숫자 대비**(양쪽 모드). "월별 달력 깔끔하게"와 묶음.

## 2. 운행완료 팝업 입력 (고가치·인터림)
- 요청: 완료 누르면 **바로 팝업으로 플랫폼+요금 입력**(앱 안 열고 나중에 X).
- 구현: 플로팅 완료 → GPS 기록 후 **투명 Activity 팝업**(플랫폼 칩 + 금액 원터치). 설정 **토글 켬/끔**.
- 권한 0. 자동화(MediaProjection 금액캡처, v15) 오기 전 **인터림** — 오면 토글로 끄고 자동으로 대체.

## 3. 운행 세션 미터 (핸들링 스타일) + 시간당 매출
- 유저 설명(핸들링): 운행버튼 활성→**시간·거리 자동 누적**, **백그라운드 지속**, 앱 재시작해도 **누적**, 식사/휴식 **일시정지·재개**.
- 유사 국내앱: 핸들러, 카택스 비즈(운행일지·지출). 개념 확립됨.
- **우리 적용 = "운행 세션" 뼈대 하나:**
  - 출근(세션 시작) → 총 운행시간·거리 **라이브 카운트**(위치 포그라운드, **이미 승인 v9** → 무심사).
  - **일시정지/재개**(식사·휴식) → 이전 기록 이어서.
  - 퇴근(세션 종료). 상태는 prefs/서버에 저장 → 앱 죽어도 복구(자가복구 원칙).
  - **3A 시간당 매출** = 세션 매출 ÷ 세션 시간. (근무시간·영업일 설정과 연결)
- **자동화 연결:** 이 세션 뼈대가 곧 자동 시작/종료(v16)와 한 몸. 수동 미터 → 자동 감지로 진화.

## 제안 순서 (다음 무심사 라운드)
0. **기능 on/off 설정 골격**(등록소 Step1) — 이후 전부 토글로 얹힘
1. **달력 격자**(빠른 win)
2. **완료 팝업 입력** + 토글
3. **운행 세션 미터**(시간·거리·정지/재개) + **시간당 매출**
- 자동화(v15·16) 도입 시 팝업입력·수동미터는 토글 off, 자동으로 대체.
