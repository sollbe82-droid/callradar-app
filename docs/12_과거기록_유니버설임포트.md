# 콜레이더 — 과거기록 유니버설 임포트 (제로 이관마찰)
*작성 2026-07-23 · 흡수 절차(08) 통과 · 멀티소스(02)의 새 source로 흡수 · 설계헌장 통과*

> 한 줄: **"쓰던 거 그대로 가져오세요. 사진만 찍으면 됩니다."**
> 다른 앱/캘린더/수첩에서 관리하던 과거 수입기록을 스샷·사진·파일로 받아 콜레이더가 정리해준다.
> 이건 신규 기능이 아니라 **멀티소스 뼈대의 새 source 2개**(import·ai) + 온보딩 스텝 하나로 흡수된다(본체 불변).

---

## 1. 왜 킬러인가 (정체성·북극성)
- **제로 이관마찰:** 어떤 수입관리 앱이든 안 갈아타는 단 하나의 진짜 이유 = "과거 데이터 다시 입력". 경쟁앱 전부 빈 화면에서 시작시킴. 우리가 "사진 한 장이면 이관" → **안 갈아탈 이유를 제거** = 경쟁사(티머니 택시투데이 등) 설치기반을 겨눈 전향 무기.
- **북극성 직격:** 온보딩 첫 3분에 "내 지난 3개월이 이미 정리돼 있네?" → "이거 왜 이제 나왔냐".
- **테스터 활성화(현 1순위) 직결:** 과거 안 버리고 넘어옴 + 한번 과거까지 넣으면 이탈 어려움(스위칭 코스트를 우리 쪽으로).
- **cold-start 해소(복리):** 과거가 첫날 들어오면 통계·패턴·핫존·AI 인사이트가 가입 첫날부터 의미. 특허 발명11(소득증빙)도 과거치까지 두꺼워짐.

## 2. 최적안 — source 2개 + 확인형
- **파일 import(`import` source):** 타 수입앱 CSV/엑셀, 캘린더 .ics → 컬럼/텍스트 매핑 → 과거 기여. 정해진 포맷 = **규칙 처리(무료·기기내)**.
- **스샷/사진 import(`ai` source):** 캘린더 화면·타 장부앱·손수첩 사진 → ML Kit OCR + AI 구조화 → 과거 기여. 자유형식 = **AI 처리(유료·일일한도, 06 비용게이트)**.
- **과거 삽입:** 실시간 매칭 아님. occurred_at 과거로 그냥 과거 운행 기여로 삽입.
- **철칙 — 확인형:** 받는 문은 넓게(뭐든 수용), **꽂는 순간은 항상 미리보기 표 → 유저 승인/수정 후에만 반영**. confidence 낮으면 "확인 필요", 자동확정 금지(헌장 7 · AI설계 06). = **문은 관대하게, 게이트는 깐깐하게**(범용성을 얻되 조잡해지지 않음).

## 3. 반박 / 대안 (자기비판)
- OCR/AI가 과거 스샷 100% 못 읽음 → 확인형 미리보기로 방어(자동 안 꽂음).
- 앱마다 포맷 제각각 → 파일은 규칙(CSV·ics), 자유형식·스샷만 AI. **처음엔 CSV/엑셀 + 캘린더 스샷 2개만** 지루하게 튼튼히(80% 룰, 원칙2·5).
- 지금 vs 나중 → **설계 확정 + source 자리 예약만**. 구현은 **스토어 자동화 승인 다음 라운드**(원칙5 덜어내는 용기). 단 온보딩 임팩트 커서 우선순위 높게.
- 심사 리스크 → **거의 없음.** 유저가 직접 주는 파일·사진이라 남의 앱 실시간 화면 안 건드림(접근성/MediaProjection과 다름). 자동화 심사 전에 먼저 넣기도 좋음.
- 프라이버시(07) → 스샷 기기내 처리 우선, AI 전송은 최소·동의.

## 4. 뼈대 연결
- **멀티소스(02):** `SOURCES`에 `import`·`ai` 한 줄. precedence 낮게(유저 수동정정 999가 늘 이김). 재업로드는 **멱등(client_uuid)**으로 중복 방지(03 자가복구).
- **AI(06):** 스샷=ai source 확인형 + 비용게이트. 규칙 되는 CSV는 무료.
- **온보딩:** "기존 기록 가져오기" 스텝(스킵 가능).
- **엑셀 내보내기의 거울:** 이미 만든 export의 반대 방향.
- **특허:** 발명2(정규화·다중소스)에 포함 — **새 특허 아님, 커버됨.**

## 5. 검증 체크리스트
- [ ] import/스샷이 source 한 줄로 흡수되나(병합·UI 무수정)?
- [ ] 과거 데이터가 확인형 미리보기 후에만 반영되나(자동확정 금지)?
- [ ] 같은 파일/스샷 재업로드가 멱등으로 중복 안 만드나?
- [ ] 규칙 되는 CSV는 무료, 자유형식만 AI(유료·한도)로 가나?
- [ ] 유저 수동정정이 import값을 늘 이기나(precedence 999)?
- [ ] 스샷 기기내 처리 우선 + AI 최소전송(프라이버시 07)?

## 6. 구현 순서 (자동화 승인 다음)
1. `import` source + CSV/엑셀 파서 + 확인형 미리보기(무료 규칙).
2. 캘린더(.ics) + 캘린더 스샷 OCR.
3. `ai` source(자유형식 스샷·수첩 사진) + 비용게이트.
4. 온보딩 "가져오기" 스텝 연결.
