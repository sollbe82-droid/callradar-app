# 콜레이더 — 데이터 권리 · 약관 설계 (복구 / 복원 / 삭제)
*작성 2026-07-21 · 개인/법인 유저의 데이터 권리와 방법 + 약관에 들어갈 항목*

> ⚠️ **법적 고지:** 나는 변호사가 아니다. 이 문서는 **기능·제품 설계 + 약관에 담을 항목 정리**이지, 최종 법률 문구가 아니다.
> 실제 이용약관·개인정보처리방침은 한국 **개인정보 보호법(PIPA)** 기준으로 **전문가 검토** 후 확정할 것.
> (지금 콜레이더 약관에 이 항목들이 들어 있는지는 현재 약관 원문을 봐야 확인 가능 — 원하면 올려줘, 대조해줄게.)

---

## 0. 왜 지금 챙기나 (사치 아님, 필수)
1. **신뢰 = 해자:** "데이터 인질 안 잡는다"가 콜레이더 신뢰의 핵심. 복구·내보내기·삭제 권리를 유저에게 준다.
2. **구글플레이 의무:** 계정 생성이 있는 앱은 **앱 내 + 웹 URL로 계정·데이터 삭제 요청 경로**를 반드시 제공해야 함(데이터 안전 양식에 삭제 URL 기재). 카카오/게스트 로그인이 있으니 **콜레이더는 대상.** (아래 출처)
3. **법(PIPA):** 유저의 열람·정정·삭제·처리정지 요구권 보장. 보관기간·파기 정책 명시 의무.

---

## 1. 유저에게 주는 3대 권리 + 방법 (자가복구 v2와 연결)
### (A) 열람·내보내기 (Access / Export)
- 언제든 내 데이터를 **PDF·엑셀·이메일**로 내보내기. (로드맵 "데이터 내보내기"와 동일)
- 설정 → "데이터 안전" → 내보내기.

### (B) 복구·복원 (Recover / Restore)
- **휴지통 복원:** 삭제한 운행/수입/경비를 N일 내 원터치 복구(자가복구 v2 소프트삭제).
- **복구 지점 복원:** 백업 시점(예: 7/20)으로 되돌리기.
- **기기 교체·초기화 복원:** 서버=진실이라 재로그인하면 서버에서 재동기화.
- 전부 설정 "데이터 안전" 화면에서 유저가 직접.

### (C) 삭제 (Delete)
- **부분 삭제:** 특정 운행/월/항목 삭제(→ 휴지통 경유, 되돌리기 가능).
- **계정·전체 삭제:** 앱 내 "계정 삭제" + **웹 URL**(구글플레이 요구). 삭제 요청 → **유예기간** 후 서버·백업에서 하드 파기.
- **내보내고 삭제:** 삭제 전 내보내기 권유(특히 세무 자료).

---

## 2. 삭제의 기술적 안전 (불변·추가형과 충돌 없이)
불변·추가형이라 "삭제"도 안전하게 설계:
```
삭제 요청 → tombstone(삭제표시) → 유예기간(예 14~30일, 되돌리기 가능)
        → 하드 파기(서버 + 모든 백업 스냅샷에서 제거) → 파기 로그 남김
```
- 즉시 소멸이 아니라 **유예 → 파기**라 유저 실수(오삭제)도 방어.
- 파기는 **백업에서도** 제거해야 진짜 삭제(백업에 남으면 삭제 아님).

---

## 3. 개인 vs 법인 — 데이터 경계 (신중히)
### 개인택시(private)
- 데이터 = **본인 소유.** 삭제 자유. 단 **세무 5년 보관** 필요 → 삭제 시 "경비 증빙이 사라져요" 경고 + 내보내기 권유.

### 법인(corp)
- **기사 개인 데이터**(현금·팁·개인 잡지출·인사이트)와 **회사 B2B 데이터**(회사에 제출 완료된 전표·정산) **경계 분리**가 핵심.
- 기사 탈퇴/삭제 시:
  - **개인 데이터** → 삭제.
  - **이미 회사에 제출 완료된 전표·정산분** → 회사 소관(회계·법정 보관). 기사 앱에선 지워도 회사 기록은 별개. → 이건 **B2B 계약·법령 이슈라 약관에 명확히 구분 기재**, 전문가 검토 필수.
- 원칙: 콜레이더는 기사 편. 회사에 안 넘긴 개인 데이터는 온전히 기사 것.

---

## 4. 약관 / 개인정보처리방침에 들어갈 항목 (체크리스트)
- [ ] 수집 데이터 종류(운행·위치·전표사진·영수증·현금·계정)
- [ ] 수집·이용 목적
- [ ] 보관 위치(서버=메인) 및 **보관 기간**(세무 5년 등, 항목별)
- [ ] 유저 권리: **열람·정정·삭제·처리정지·이동(내보내기)** 및 행사 방법
- [ ] **삭제 요청 방법(앱 내 + 웹 URL)** 및 처리 기간·유예
- [ ] 백업·복구 범위와 파기 정책(백업 포함 파기)
- [ ] 제3자 제공/처리위탁 고지 — **AI 처리 시 어떤 데이터가 어디로** 가는지(스며든 AI 하이브리드 반영)
- [ ] 개인/법인 데이터 경계, 회사 제출분 처리
- [ ] 탈퇴 시 데이터 처리
- [ ] 개인정보 보호책임자·문의 창구

## 5. 반박 / 자기비판
- **"유예기간이 즉시삭제 원하는 유저에게 불편?"** — 즉시 하드삭제 옵션도 제공하되 기본은 유예(오삭제 방어). 유저가 "즉시 영구삭제" 선택 가능.
- **"법인 데이터 경계가 복잡"** — 맞다. 그래서 지금 단정하지 말고 **약관에 구분만 명확히**, 실제 B2B 계약 시 회사별로 확정. (driver_type·정산 뼈대와 연결)
- **내 한계:** 실제 법 문구는 전문가 몫. 나는 **무엇을 담아야 하는지**까지.

---

## 6. 뼈대 연결
- **자가복구 v2:** 복구·복원·삭제(휴지통·유예·파기)의 기술 토대.
- **멀티소스:** 삭제 = tombstone 기여, 파기까지 불변·추가형 규율 유지.
- **driver_type:** 개인/법인 데이터 경계·보관기간이 profile로 갈림.
- **화면 등록소:** "데이터 안전" 카드(설정 surface).

---

## 7. 검증 체크리스트
- [ ] 앱 내 + 웹 URL 삭제 경로가 둘 다 있나(구글플레이 요구)?
- [ ] 삭제가 백업에서도 파기되나(진짜 삭제)?
- [ ] 오삭제 방어 유예기간 + 되돌리기가 있나?
- [ ] 개인택시 삭제 시 세무 5년 보관 경고·내보내기 권유가 뜨나?
- [ ] 법인에서 개인 데이터와 회사 제출분이 분리 처리되나?
- [ ] AI에 넘어가는 데이터가 약관에 고지되나?
- [ ] 현재 약관 원문과 이 항목들을 대조했나? (원문 확보 후)
