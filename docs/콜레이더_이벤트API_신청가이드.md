# 전국 이벤트 데이터 — API 신청 행동지침 (대표님 할 일)

목표: 공연·콘서트·스포츠·축제·크루즈 입항 등 **전국 이벤트를 자동 수집** → 지역 설정하면 그 지역 것 + 추가설정 지역이 보이게.
방식: 아래 키를 발급받아 **인증키(서비스키)를 나에게 전달** → 내가 서버(Render) 환경변수에 넣고 자동수집 연결. (공개데이터 키라 민감도는 낮지만, 운영키면 유출 주의.)

우선순위대로:

## 1. 한국관광공사 TourAPI — 전국 축제·행사 (최우선, 커버리지 최대)
- 무엇: 전국 지역축제·행사 일정(지역·기간·좌표 포함). 지역 필터에 딱.
- 신청: data.go.kr에서 **"한국관광공사_국문 관광정보 서비스(TourAPI)"** 검색 → 활용신청(개발계정 자동승인). 
  - 사용할 오퍼레이션: 행사정보 조회(`searchFestival`), 지역기반 조회(`areaBasedList`).
- 받을 것: **일반 인증키(서비스키)** → 나에게 전달.

## 2. KOPIS 공연예술통합전산망 — 공연·콘서트 (최우선)
- 무엇: 전국 공연·콘서트 일정 + **박스오피스(인기순위)** → "규모 있는/인기 있는" 것 선별 가능.
- 신청: **kopis.or.kr** 회원가입 → 오픈API 서비스 신청 → 인증키 발급. (data.go.kr 아님, KOPIS 자체 포털.)
- 받을 것: KOPIS **서비스키** → 나에게 전달.

## 3. 스포츠 일정 (야구·축구 등)
- 무엇: 프로야구/K리그 홈경기 일정(경기장·시간) → 경기장 주변 수요.
- 신청: data.go.kr에서 **"경기일정"** 검색(국민체육진흥공단·구단 데이터셋). 공개 API가 빈약하면 **관리자 등록**으로 대체(내가 서버에 넣음).
- 받을 것: 있으면 서비스키, 없으면 "관리자 등록" 처리.

## 4. 크루즈 입항 / 선박 입출항
- 무엇: 인천·부산·제주 등 크루즈 입항 일정 → 항구 주변 수요.
- 신청: data.go.kr에서 **"크루즈 입항"**, **"선박 입출항 예정"**(해양수산부·항만공사) 검색 → 활용신청.
  - (인천항 크루즈는 앞서 얘기 나온 icpa.or.kr도 참고.)
- 받을 것: 서비스키 → 나에게 전달.

## 5. 집회·시위
- 공개 API 사실상 없음(민감). → **관리자 등록 / 뉴스 기반**. 신청 불필요.

---

## 대표님 행동 체크리스트
1. [ ] data.go.kr 로그인 → **TourAPI(행사·축제)** 활용신청 → 인증키 복사.
2. [ ] **kopis.or.kr** 가입 → 오픈API 신청 → 인증키 복사.
3. [ ] data.go.kr에서 **"크루즈 입항 / 선박 입출항"** 활용신청 → 인증키 복사.
4. [ ] (선택) data.go.kr **"경기일정"** 활용신청.
5. [ ] 발급된 **인증키들을 나에게 전달** → 서버 환경변수 연결 + 자동수집 코드 작성.
   - 키 전달 어려우면, 내가 서버 환경변수 넣는 위치(Render Dashboard → Environment)를 알려드리고 대표님이 직접 붙여넣어도 됩니다.

## 내가 할 일 (키 받은 뒤)
- 서버: 각 API 파서 + 정규화 → events 테이블에 자동 적재(중복 제거, 규모/인기 필드로 정렬).
- 앱: 지역 설정값으로 이벤트/공항/추천 필터 + 추가지역 설정.
- 관리자 등록 화면(집회·스포츠 폴백)도 유지.

## 참고
- data.go.kr 개발계정은 보통 자동승인, 트래픽 한도 있음(운영단계 심의 별도).
- 승객예고 등 이미 승인받은 공항 세트처럼, 위 키도 같은 방식으로 붙입니다.
