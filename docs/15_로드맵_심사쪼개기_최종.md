## 🧱 v13 — "에러 없는 앱" 뼈대 + 마감 (권한 0 · 즉시심사)
데이터 무결성이 신뢰=해자. 화려한 기능보다 이 밑바닥 먼저.
- **경로 C (데이터 뼈대):** client_uuid **멱등**(같은 기록 두 번 안 생김) + **소프트삭제**(오삭제 복구) + 전표 **inbox**(전표↔운행 매칭). → 투폰 충돌·오삭제·전표 어긋남 에러 원천 차단.
- **계정 합치기** (이미 쪼개진 테스터) + **기기 플랫폼 다중선택** UI (서버 완료, 앱만).
- **과거기록 임포트 마무리:** OCR 튜닝(테스터 원문 반영) + 파일(CSV/엑셀) 가져오기.
- **월별 달력 화면**을 타앱처럼 깔끔하게(일자별 수입·지출·합계).
- 마감 다듬기: 오버레이/토스트 정리, 라이트모드 색 미세조정.
- **카드 show/hide 토글** (화면 등록소 v2 Step1 · docs/16) — "필요한 것만"의 80%를 값싸게.

## 📸 v14 — 스크린샷 공유 = MediaProjection 발판 (권한 1: FGS mediaProjection)
- 유저가 버튼 눌러 **화면 캡처 → 콜레이더 워터마크 → 공유** (코드 이미 대기 중).
- **목적:** 화면캡처 권한을 "유저 개시"로 스토어에 정식 각인 → 다음 자동 금액캡처의 발판.
- 제출: FGS type=mediaProjection 선언 + 인앱 동의화면 + **시연영상**. 이 라운드 심사 게이트 = 이것 하나.

## 💰 v15 — 반자동 금액 자동입력 (승인된 MediaProjection 위)
- 마감 시 **플로팅 버튼 1탭 → 전표/미터기 화면 스샷 → OCR → 금액 자동채움.**
- 같은 승인된 권한 + 유저 개시라 심사 범위 안. **우버 파싱 95→100.**
- 결과: "금액 수동입력"이 사라짐 = 자동화의 절반 완성.

## 🛰️ v16 — 자동 시작/종료 경계 (권한 1: 활동인식)
- **지오펜스 + ActivityRecognition**으로 탑승/하차 자동 감지 → 플로팅 안 눌러도 운행 경계 생성.
- 위치는 이미 승인됨(v9). 활동인식 권한 1개만 추가 선언.
- 결과: 시작·종료도 거의 0터치.

## 🚀 v17 — 완전자동판 완성 + 유료화
- 시작/종료 자동 + 금액 자동 = **v6 완전자동판의 스토어 합법 버전 완성.**
- **게이트 토글(entitlement)** → 서버 구독 상태로 전환 = 인앱결제/구독. (게이트는 v13~부터 미리 심어둠 → 유료화 때 이중작업 0.)
- **이게 최종 상업적 가치.**

## 심사 쪼개기 규칙 (매 제출)
1. 민감권한은 **한 번에 하나만** 추가(v14 캡처, v16 활동인식). v13·v15는 권한 0.
2. 권한 추가 제출엔 **선언 + 시연영상** 필수.
3. **접근성 스크래핑은 스토어판에 절대 안 올림**(밴). 완전 0터치는 pro/APK만.
4. "심사 통과 후 몰래 켜기" 금지 — 승인된 동작만. (정책 위반·밴)
5. 각 단계는 테스터에 바로 배포·검증 → 버그는 실사용 피드백으로.
