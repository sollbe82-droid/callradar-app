## 1. 이 채널을 뭐로 할 것인가 — 가장 중요한 결정

### 하면 안 되는 것: 앱 기능 소개 채널

"오늘은 자동기록 기능을 소개합니다" 를 매일 올리면 **3주 안에 소재가 떨어집니다.**
그리고 아무도 안 봅니다. 광고를 매일 보러 오는 사람은 없습니다.
자동화 티가 나는 채널은 대부분 여기서 시작합니다 — 할 말이 정해져 있으니 형식이 굳습니다.

### 해야 하는 것: **매일 저녁 택시 기사 브리핑**

콜레이더 서버에는 **기사 600명의 실제 운행 데이터**와 **오늘의 행사·공항·야구 일정**이 있습니다.
이건 다른 누구도 못 만드는 콘텐츠입니다. 그리고 **매일 내용이 저절로 다릅니다.**

```
오늘 저녁 브리핑 (예시)

  · 잠실 KBO 파장 21:40 — 지금 출발하면 맞습니다
  · 인천공항 택시 대기 143대 — 지금 가면 헛걸음입니다
  · 어제 서울 기사 평균 시간당 27,600원 · 가장 좋았던 시간 새벽 2~4시
  · 킨텍스 K-POP 어워즈 오늘 파장 22:00
```

**콜레이더는 이 브리핑의 출처로만 등장합니다.** "콜레이더 데이터 기준" 한 줄.
그게 훨씬 강한 광고입니다 — 매일 도움을 받은 사람은 앱을 깝니다.

### 이 결정이 자동화 문제까지 같이 풉니다

자동 티가 나는 이유는 **내용이 매일 같기 때문**입니다.
데이터에서 뽑으면 제목·수치·결론이 **매일 저절로 달라집니다.** 흉내가 아니라 진짜로 다릅니다.

## 3. "자동인 걸 모르게" — 구체적으로 무엇을 하는가

자동 채널은 아래 10가지로 들킵니다. 하나씩 막습니다.

| # | 들키는 지점 | 우리가 하는 것 |
|---|---|---|
| 1 | 매일 같은 내용 | **데이터에서 뽑아 진짜로 매일 다름** (1번 참조) |
| 2 | 정각 업로드 | 19:40~20:20 사이 **분 단위 랜덤** |
| 3 | 매일 빠짐없이 | **주 6일.** 일요일은 쉽니다. 사람은 매일 안 올립니다 |
| 4 | 제목 공식이 같음 | 그날 **가장 센 숫자**를 제목에 씀 → 문장 구조가 매일 바뀜 |
| 5 | 썸네일이 한 틀 | 내용 종류별 **4가지 틀**(공항/야구·행사/매출/경고) 중 그날 것 |
| 6 | 목소리가 평평함 | 문장마다 속도·높이를 조금씩 흔들고 쉼표에 숨 넣기 |
| 7 | 설명란이 복붙 | 첫 두 줄은 그날 수치, 나머지만 고정 |
| 8 | 댓글 무응답 | **매일 아침 댓글 초안을 만들어 드리고 대표가 확인 후 게시** |
| 9 | 커뮤니티 탭 비어 있음 | 주 2~3회 투표("오늘 어디가 잘 나왔나요") |
| 10 | 세상일에 반응 없음 | 불꽃축제·연휴·폭우·파업이 뜨면 **그날 첫 줄이 그걸로 바뀜** |

### 특히 8번은 자동화하지 않습니다

댓글은 **사람이 보면 바로 압니다.** 기계 답글은 채널을 죽입니다.
그래서 이렇게 합니다.

```
매일 아침 08:00 — 어제 달린 댓글을 모아 답글 초안을 만들어 카톡/파일로 드림
대표          — 훑어보고 고칠 것만 고쳐서 그대로 붙여넣기 (5분)
```

**답글 다는 사람은 대표여야 합니다.** 기사가 "이 사람 진짜 택시 뛰는구나" 를 아는 순간
채널의 성격이 달라집니다. 그게 우리가 가진 제일 큰 무기입니다 —
경쟁 채널은 데이터도 없고 법인 기사도 아닙니다.

### 그리고 주 1회는 사람이 직접

일요일 쉬고, **주 1회 롱폼은 대표 목소리로** 녹음하시는 걸 권합니다(5분).
이게 있으면 나머지 6편이 TTS여도 채널 전체가 사람 채널로 읽힙니다.
없으면 아무리 잘 만들어도 언젠가 티가 납니다.

## 4. 업로드 시간을 왜 저녁 19:40~20:20 으로 잡았나

기사의 하루에서 폰을 볼 수 있는 시간은 정해져 있습니다.

```
06~09  출근·오전 피크    못 봄
12~13  점심 대기         짧게 봄
19~21  저녁 식사·교대     ← 가장 길게 봄
02~04  심야 대기         봄. 다만 이때 올리면 다음날 노출이 죽음
```

저녁에 올리면 **그날 밤 영업에 바로 쓸 수 있습니다.** 야구 파장, 공항 대기, 행사 —
전부 밤에 쓰는 정보입니다. 아침에 올리면 이미 늦습니다.
