## 2. 이번 세션에 끝낸 것 (파일 이미 PC에 저장됨)
1. **더보기 전면 재구성** — `app/src/main/java/com/callradar/app/screen/MoreScreen.kt`
   - 상단 4탭(분석/랭킹/링크/설정) → 성격별 그룹 타일 랜딩 + **⊞아이콘 / ☰목록 토글**(prefs `more_view_mode`).
   - 흩어진 정산 항목을 **"정산 설정" 하위화면 하나로 통합**(기사유형·사납금·수수료·LPG·고정지출·분배율·연차).
   - 분석/랭킹/링크/기능등록소/정산설정은 뒤로가기 헤더 하위화면으로 재사용(컨테이너만 교체).
   - **LPG 다이얼로그 개선**: 개인=유가보조금(원/L) 직접 입력 부활(기본 221), 법인=경감률(%)/**회사 고정단가(원/L) 토글**.
   - 내 이름 아이콘 🙍→🙋 교체.
2. **LPG값 → 순수익 연결** — `screen/HomeScreen.kt` + MoreScreen
   - LPG 저장 시 일 가스 실부담(원)을 계산해 prefs `lpg_daily_cost`에 저장(단일 소스).
   - 홈 오늘 순수익 + 월급명세서에 "가스비" 줄로 차감 반영. 예전 `lpg_daily`(리터)를 원 비용으로 오용하던 버그도 수정.
3. **공항 혼잡도 그래프 복구** — `screen/AirportScreen.kt`
   - 원인: 서버 `/api/airport/passengers`가 실서버에서 `[]` 반환(공공 승객예고 API가 빈 값).
   - 조치: 클라가 깨진 passengers 대신 **`/api/airport/cached`의 `t1.hourly/t2.hourly`로 자동 폴백** + 둘 다 없으면 "불러오지 못했어요·새로고침" 안내. `TerminalData`에 `hourly` 필드 + 파싱 추가.
4. **버전** — `app/build.gradle.kts` : versionCode **16**, versionName **1.6**.
5. **서버 수정** — `C:\CallRadarServer\index.js` (⚠️ 배포 소스 확인 필요, §4 참고)
   - `hourly` 계산 앞 5시간 → 12시간 확장(도착항공편 있는 시간대만).
   - `/api/airport/passengers`가 비면 캐시 hourly로 폴백(`buildHourlyFromCache`).
   - `/api/expenses/summary`에서 **LPG 카테고리 지출을 business/personal 합산에서 제외**(설정LPG와 이중계산 방지). LPG 실제기록은 `lpgAmount`로 유지.
6. 빌드 스크립트 — `C:\CallRadar\build_v16.bat` (더블클릭 시 JAVA_HOME=AS jbr 잡고 `gradlew bundleRelease`).

**새로 쓰는 prefs 키:** `more_view_mode`, `lpg_subsidy`, `gas_method`(rate/fixed), `gas_fixed`, `lpg_daily_cost`.

## 4. ⚠️ 서버 배포 미해결 (반드시 확인)
- `C:\CallRadarServer` = **git 저장소 아님**(`.git` 없음 → git push 불가). 이번 서버 수정은 여기(index.js, 79KB)에 들어감.
- `C:\CallRadar\server` = **git 저장소 맞음**(`.git` 있음). 근데 그 `index.js`는 **95KB로 서로 다른 파일**(약 16KB 더 큼).
