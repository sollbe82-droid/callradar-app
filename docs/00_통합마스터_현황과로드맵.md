### C. v9 통과 직후 — 코드 (v10 배치, 개발현황 우선순위)
1. **4-1 전표 금액 자동 채우기 (최우선, ⑩)** — GPS운행(금액 빈 것)에 전표금액 시간매칭. **단일 건부터**, 같은 플랫폼 다건은 OCR 시간 불안정으로 보류
2. **4-2 공항 개선 (⑨)** — 입국 수속인원 크게 위에 · 도착편 시간대 그룹핑 · 출국탭 안만듦 · 혼잡도 미작동 원인규명
3. **4-3 현금·팁·계약콜 (②⑭⑯)** — 현금 3초입력(큰 키패드·원터치) · 팁 신설(요금 분리, 회사정산 무관) · 계약콜 정산(월단위+회사정산 토글)
4. **4-4 잡지출 분류 (⑮)** — 법인:개인소비 파악 / 개인택시:경비증빙 창고(→연말 세무 경비총액)
5. **4-5 다듬기(⑦) + SetupGuide 버그수정** — 오버레이 텍스트·토스트 축소·배터리 예외 안내 / **SetupGuide는 이번 방 설계대로 뒤로가기→홈 + 기종 폴백 + 플로팅 도움말 방향 반영**

### D. 나중 / 별도 심사
- **⑥ 화면 스샷 자동금액** (MediaProjection 별도 심사 · 전표매칭 난관 우회하는 더 깔끔한 길)
- **AI "스며든 AI"** — 스샷 만능입력 → 자연어 수입질문 → 백그라운드 인사이트 → 콜 제보사진→핫존. 하이브리드 비용(규칙=무료, 자유형식=AI 유료, 무료 일일제한)
- **미터기 BLE 연동** (프로토콜 비공개 → 제조사·회사 제휴 B2B로만)
- **개인택시 세무** (신고자료 패키지까지, 직접신고는 보류) · **영수증 5년 원본 보관** · **데이터 내보내기**(PDF·엑셀·이메일) · **계정 확장**(구글·네이버 자리) · **콜 공유**
