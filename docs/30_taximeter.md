# docs/30 — 콜레이더 요금 미터기 (GPS 기반 추정) 설계

작성: 2026-07-26 · 상태: 설계(제안)

## 경쟁앱 분석 (택시미터기 전국 / hi_jeon)
- GPS 기반 실시간 요금 계산기. 전국 9개 지역 요금표.
- 심야·시계외 할증 자동. 운행 종료 요약(기본/거리/시간/할증). 운행기록 자동저장. 홈 위젯.
- 인앱 구매(유료 요소). 리뷰 5.0.

## 우리가 만들 것
주행 중 GPS로 거리·저속시간을 재서 요금을 **실시간 추정**하고, 종료 시 콜레이더 기록에 저장.
카풀·길빵·예약처럼 정식 미터기가 없는 상황의 **참고용 추정 미터기**.

### 필수 원칙
1. **"참고용 추정" 명확 표기** — 법적 미터기 아님(GPS 5~10% 오차). 분쟁 방지.
2. **요금표 서버 다운로드** — 지역·연도별 요금이 자주 바뀜 → `/api/meter/rates`로 내려받아 적용(규칙 다운로드 구조 재활용). 앱 업데이트 없이 요금 갱신.

## 요금 계산 모델 (한국 택시 표준)
```
요금 = 기본요금
     + 거리요금  (기본거리 초과분에 대해 distanceUnitFare 원 / distanceUnitM 미터)
     + 시간요금  (속도 < slowKmh 일 때 timeUnitFare 원 / timeUnitSec 초)  ← 정차·서행 시 시간요금
그 후 할증(곱연산):
     × (1 + nightPct/100)      심야 (nightStart~nightEnd 시)
     × (1 + intercityPct/100)  시계외(도심 밖) — 수동 토글 또는 지오펜스
```
- 거리요금과 시간요금은 **동시 적용이 아니라**, 속도가 기준(약 15km/h) 이상이면 거리요금, 미만이면 시간요금(택시 미터 방식). 구현: 매 GPS 틱마다 이동거리로 거리요금 누적, 저속이면 경과시간으로 시간요금 누적.

### 지역별 요금표(예시 스키마 — 실제 값은 서버에서, 반드시 최신 확인)
```json
{
 "version": 1,
 "regions": {
   "서울_중형": { "base": 4800, "baseM": 1600, "distUnitFare": 100, "distUnitM": 131,
                 "timeUnitFare": 100, "timeUnitSec": 30, "slowKmh": 15,
                 "nightPct": 20, "nightStart": 22, "nightEnd": 4, "intercityPct": 20 },
   "경기_중형": { ... }, "인천_중형": { ... }, ... (9개 지역)
 }
}
```
> ⚠️ 위 숫자는 예시. 실제 요금은 지역·차종·연도별로 다르며 자주 인상됨 → **출시 전 각 지자체 고시 요금으로 채워야 함.**

## UI / 흐름
- **미터기 화면**: 큰 요금 숫자(실시간), 거리(km)·경과시간, 지역 선택, 심야/시계외 배지, [시작]/[정지].
- 상단 "참고용 추정" 배지 상시.
- **정지 시**: 요약(기본/거리/시간/할증/합계) → "이 요금으로 기록 저장"(운행기록에 platform=미터기로 저장, 기존 /api/trips/manual 재활용).
- 진입: 홈 상단 또는 더보기. (플로팅 '운행 버튼'과 연계 가능)

## 기술
- **위치**: FusedLocationProvider (play-services-location 이미 의존성 있음). 2~3초 간격, 거리=Haversine 누적, 속도=거리/시간.
- **백그라운드 주행**: 화면 꺼져도 재려면 **포그라운드 서비스(location)** 필요 + 매니페스트 FGS location 선언 + ACCESS_FINE_LOCATION(이미 있음)·FOREGROUND_SERVICE_LOCATION 권한. v1은 "화면 켠 채" 우선, v2에서 포그라운드 서비스.
- **요금 엔진**: 순수 함수 `calcFare(distanceM, slowSec, rate, isNight, isIntercity)` → 단위 테스트 가능.
- **정확도**: GPS 튐 보정(정확도 나쁜 포인트 버림, 최소 이동거리 필터).

## 단계
- **v1**: 화면 켠 채 GPS 미터(서울 기본요금표) + 심야 자동 + 시계외 수동토글 + 정지 후 기록저장 + "추정" 배지.
- **v2**: 지역 9종 요금표(서버 다운로드) + 포그라운드 서비스(화면 꺼짐 대응) + 홈 위젯.
- **v3**: 유료(프로) — 지역 자동감지, 정밀 보정, 위젯 커스텀.

## 수익화
- 무료: 서울 요금 + 화면 켠 채.
- 프로(유료): 전국 요금표·백그라운드·위젯·정밀보정.

## 리스크
- **요금 정확성**: 요금표가 틀리면 신뢰 붕괴 → 서버 갱신 + "추정" 표기 필수.
- **GPS 오차**: 터널·도심 빌딩에서 튐 → 필터링. 그래도 정식 미터기와 차이 있음(명시).
- **배터리**: 지속 GPS는 배터리 소모 → 간격·정확도 균형.
