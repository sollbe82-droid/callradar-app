# 콜레이더 — v18 설치 후 테스터 피드백 & 조치 (v19 예정)

*작성 2026-07-25 · 루이 실기기(SM-S948N, 야간기사) 피드백. v18은 심사 중이라 아래는 v19(권한0·심사무해)로.*

---

## 1. 야간·일차 기사 날짜 분리 버그 (dayStart) — 핵심
- **현상:** 17시~09시 근무. 자정 넘긴 운행은 다음 날짜로, 자정 전은 어제 날짜로 **쪼개져서** 기록·월별 달력에 나뉨. 근무시간을 정하면 자정 넘어도 지정 날짜에 기록되길 원함.
- **원인:** 서버가 날짜를 자정(0시) 기준으로 끊음. 영업일 시작(dayStart) 설정 UI는 있으나 **홈 `/api/today`에만 적용**되고 `/api/trips`·`/api/stats`·`/api/summary`·`/api/expenses`엔 미배선(docs/22 #8, docs/21 §5). → 월별 달력·통계·마감은 자정 기준 그대로.
- **조치:** 위 서버 엔드포인트에 `dayStart` 파라미터 추가(자정 경계를 dayStart시간만큼 뒤로) + 앱 기록/월별/통계/마감에서 `day_start_hour` 전송. 자정 크로스 귀속 전부 이 기준.
- **크기:** 중 (서버 SQL 다수 + 앱 여러 화면 · 데이터 신성 조심).

## 2. 더보기에서 폰 뒤로가기 → 앱 종료 — ✅ 완료(코드 반영)
- **원인:** 탭·하위화면에 하드웨어 뒤로가기(BackHandler) 처리가 없어 시스템 기본동작(액티비티 종료)이 실행됨.
- **조치(반영됨):** `MoreScreen` 하위화면 → 더보기 홈으로, `MainWithTabs` 홈 아닌 탭 → 홈 탭으로 BackHandler 추가. 홈 탭에서만 기본 종료. 마감 오버레이는 기존 BackHandler 유지.

## 3. 지난 기록·영수증·타앱 기록을 기록 메뉴에서 등록 (실적 가져오기 / 카메라 / 갤러리)
- **요구:** 기록 탭에서 "실적 가져오기 · 카메라 · 갤러리"로 과거 기록/영수증/다른 앱 캡처를 등록.
- **현재:** 임포트 진입이 흩어짐 — 과거기록=`ImageImportActivity`(갤러리), 전표=마감화면. 통합 진입/카메라 촬영 없음.
- **조치:** 기록 탭 상단에 **가져오기** 진입 → 📷카메라 / 🖼갤러리 / 📄파일 → 추출 → **하나의 확인 표** → 저장(docs/21 유니버설 임포트). 카메라 촬영 경로 신규.
- **크기:** 큼.

## 4. 회사제출 OCR 안 됨 (분리 필요)
- **현상:** 마감(회사제출) 화면에서 전표 OCR이 안 읽힘.
- **원인:** `ReceiptOcr`(ML Kit 한글). 모델 미다운로드/전표 레이아웃/정규식 불일치 시 총액·개별운행 **아무것도 못 뽑음**. 그러면 화면이 사실상 진행 불가.
- **조치:** OCR을 **필수 경로에서 분리** — OCR 실패해도 **날짜+금액 수동 입력만으로 저장** 가능하게(OCR은 보조). ML Kit 모델 선다운로드 안내.
- **크기:** 중.

## 5. 22일 영수증 찍어도 그날/다른날 아예 기록 안 됨 — 핵심 버그
- **원인(★):** 마감화면의 **회사제출(`/api/daily-settlement`)과 기록(`/api/trips`)이 분리**돼 있음. "기록에 N건 추가" 버튼은 `parsedTrips`(전표 플랫폼 소계 줄)가 있어야만 뜸 → OCR이 소계를 못 뽑으면 **기록 0건**. 결국 회사제출만 저장되고 **기록 탭엔 안 뜸** → "기록이 안 된다"로 체감.
- **조치:** 확인 표 기반으로 **날짜+금액만으로도 그 날짜에 기록 저장**(멱등 `imp_{유저}_{날짜}`) + 회사전송 **동시**(docs/21 v17-a). OCR 성패와 무관하게 저장 가능.
- **크기:** 중~큼 (4번과 같은 화면).

## 착수 순서 제안 (v19, 전부 권한0·심사무해)
1. **뒤로가기(2)** — ✅ 완료.
2. **dayStart 전면(1)** — 야간·일차 기사 핵심. 서버+앱.
3. **마감/영수증 저장 폴백(4·5 핵심)** — OCR 실패해도 날짜+금액으로 기록 저장 + 회사전송 동시.
4. **유니버설 임포트 메뉴(3)** — 기록 탭 가져오기(카메라/갤러리/파일) + 확인 표. (제일 큰 덩이, 마지막)
