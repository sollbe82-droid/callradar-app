# 콜레이더 — 유니버설 매출 임포트 설계 (전표·타앱·손글씨) v17

*작성 2026-07-24 · 대표(클로드) 설계 · 정본. docs/12(유니버설임포트) 구현설계 + docs/06(스며든 AI)·18(유료경계) 연결.*
*헌장 방식: 최적안 → 내 안 반박 → 뼈대 연결 → 검증.*

> 한 줄: **아무 출처(우리 전표·남이 쓰던 앱 스샷·손글씨 노트·월 캘린더) 사진 1장 → 하나의 확인 표 → "맞나요?" → 그날 자에 기록.**
> 원칙: 포맷별 파서를 무한히 안 만든다. **구조적인 건 무료 규칙(온디바이스), 자유형식·손글씨는 AI가 흡수. 최종 착지점은 하나.**
>
> ★ **최소입력 원칙 (킬러기능의 심장):** 장부는 **날짜 + 금액만으로 성립**한다. 시간·출발지·목적지는 **전부 선택(미정 허용)**. 있으면 풍부해지고, 없어도 장부·통계·정산 다 돌아간다. 타앱/노트 유저는 "다 적어야 한다"는 순간 이탈한다 — **한 칸(금액)만으로도 들어와야 흡수된다.**

---

## 1. 정체성 필터 (북극성)
"누가 써도 간편 — 왜 이제 나왔냐." 이관 마찰 0 = 온보딩 킬러(docs/12). 남이 뭘 쓰던 사람이든, **사진 한 장이면 우리 앱으로 넘어온다.** 실패해도 절대 안 막힘.

## 2. 문제 (왜 지금 안 되나 + 범용성 요구)
- 마감 전표: 회사전송·기록입력이 **따로 수동 버튼** + 기록이 **영수증 날짜 아닌 오늘**로 들어감 → 22일이 22일에 안 꽂힘.
- 임포트가 **우리 달력 격자 하나**만 상정 → 남이 쓰던 앱은 레이아웃이 제각각, **손글씨 노트**는 아예 대상 밖.
- 미터기·앱·손글씨 전부 포맷이 달라 규칙 파서만으론 못 덮음.
- **★현재 최악의 이탈 버그:** 수동 과거기록 입력이 **목적지를 강제**(`RecordsScreen` 337행 `if (manualDest.isNotBlank())`) → 목적지 안 적으면 저장이 조용히 무시됨. "과거기록 넣으려면 시간·출발·목적지 다 적어야 하냐"는 문의 폭주의 원인. → 최소입력 원칙 정면 위반.

## 3. 최적안 — "하나의 깔때기 + 계단식 추출"
입력(사진 1장, 아무 출처) → **[추출 엔진]** → **공통 확인·수정 표** → **[예]/수정** → 서버 `import/bulk`(멱등).

### 3-1. 공통 확인 표 (모든 출처가 여기로 모임)
| 날짜 | 수입 | 지출 | (전표면 플랫폼 소계) |

- 자동으로 채워져 뜨고, 셀은 **전부 손으로 수정 가능**.
- **[예]** → 저장. **[아니요/수정]** → 날짜·금액 고쳐 저장(오차 원천 제거, 루이 안).
- **필수 = 날짜 + 금액.** 시간·출발지·목적지 빈칸이면 **미정으로 저장**(막지 않음). ← 최소입력 원칙.
- 자동확정 절대 없음 — 사람 확인이 마지막 관문(헌장 원칙7 · docs/07).

### 3-1b. 진입 UX — "다른 앱 매출 가져오기" 두 갈래
가져오기 화면에서 출처를 먼저 고름(보기 깔끔·기대치 명확):
- **📄 파일 가져오기 (엑셀/CSV):** 앱이 export 지원하면 여기로. **OCR 없이 구조 데이터 직접 파싱 = 최상위 정확도·무료.**
- **🖼 이미지(스샷) 가져오기:** export 안 되는 앱·화면 캡처·**손글씨 노트**는 여기로. 아래 계단식 추출.
- (우리 전표는 마감 화면의 "전표 스캔"이 전용 진입 — 같은 확인 표로 합류.)

### 3-2. 계단식 추출 엔진 (정확도·비용 순 · 게이트 docs/06·18)
0. **파일(엑셀/CSV) — 무료·최정확:** 열 자동매핑(날짜/수입/지출 후보 추론) → 확인 표. OCR 오차 없음.
1. **이미지 무료·온디바이스(ML Kit OCR + 규칙):** 우리 전표(총합계/플랫폼 소계/개별거래), 표준 달력 격자, "MM/dd + 금액" 패턴. **되면 여기서 끝(무료·조용함).**
2. **이미지 AI·자유형식(일일 무료 N장 → 초과 유료):** 1단계가 못 잡으면 = 낯선 앱 레이아웃·흐트러진 표·**손글씨 노트** → 이미지(또는 OCR텍스트)를 **멀티모달 AI**에 → {날짜, 수입, 지출} 구조화. confidence 낮으면 셀에 "확인 필요" 표시.
3. 어느 경로든(파일·규칙·AI) 결과는 **같은 확인 표**로 착지. 새 앱/새 노트가 나와도 **뼈대 불변, 한 줄 흡수.**

### 3-3. 전표(가장 구조적) — 삼중 교차검증
전표엔 개별 거래(시간+금액)까지 있음. 3번 실검산: 카카오 8건=158,700 · 신용 3건=46,100 · 티머니 6,600 · **개별합=소계=총합계=211,400 정확일치.**
→ 셋이 맞으면 "확인됨 ✅"(바로 [예] 유도), 어긋나면 경고 → [아니요]로 확정.
→ 날짜 자동채움: ① 집계시간 "07/22…" MM/dd → ② 캘린더 선택일 → ③ 오늘. 미터기 글자 달라도 표에서 수정하니 **안 막힘.**

## 4. 내 안을 내가 깜 (반박/대안)
- **앱마다 파서 하나씩:** 유지불가·무한증식. ✗ 원칙5(덜어내는 용기). → 구조적인 것만 규칙, 나머지 AI.
- **전부 AI로:** 간단하지만 비용·프라이버시·오프라인 불가. ✗ → **무료 규칙 우선, AI는 폴백**(대부분 무료로 끝남).
- **순수 자동(확인 생략):** 손글씨·낯선 앱은 오차 큼 → 데이터 신성 위반. ✗ → **확인 표 필수**(오차 클수록 사람 관문이 값어치).
- **개별거래 12건 무조건 운행 생성:** 기존 GPS 운행과 이중계산. ✗ → 소계=진실 기준선, 개별은 검증·시간매칭용.

## 5. 뼈대 연결
- **멀티소스(02):** `source="import"`(또는 "전표") 기여 한 줄. 전표=그날 플랫폼 합계의 진실 기준선.
- **AI 스며든(06):** 자유형식 추출 = `ai` source, confidence 낮으면 "확인 필요". 규칙=무료(온디바이스)·AI=유료(일일한도). 기본은 조용함.
- **멱등/자가복구(03·경로C):** 키 `imp_{유저}_{날짜}` → 재스캔 덮어쓰기, 중복 0. (서버 `import/bulk` 이미 구현·배포됨)
- **⑩ 전표→운행 금액매칭 (★핵심·빈칸만 채우기):** 플로팅/GPS로 **장소·시간만 있고 금액이 빈 운행**에, 전표 개별거래를 **시간매칭(±15분)** 해 **금액만** 채움. 매칭 안 된 개별거래는 "출발·도착 미정 + 금액"으로 신규. 소계로 요약 폴백.
- **precedence "빈칸만 채우기"(02·원칙7):** 전표 자동금액은 **금액 빈 운행만** 채운다. **이미 금액이 있으면 절대 안 덮고** "전표와 일치? ✅ / 다름 ⚠️"만 표시(교차검증). 유저 수동값(precedence 999)이 항상 최고 — 자동이 못 덮음.
- **데이터 권리(07):** AI 경유 시 이미지 추출 후 미보관·동의 1줄, 개인식별 최소.
- **야간·일차 영업일 시작(dayStart) — 전면 일관 적용:** 설정 UI는 이미 있음(MoreScreen "🕐 영업일 시작", 개인·일차·야간 누구나). **현재 홈 "오늘 매출"(`/api/today`)에만 적용되고 기록 달력·월별·통계·마감엔 안 걸림** → 야간/일차 기사가 "설정해도 장부 안 바뀜"으로 느낌. → 서버 `/api/trips`·`/api/stats`·`/api/summary`·`/api/expenses`에 `dayStart` 파라미터 추가하고 앱 전 화면에서 전송. 자정 크로스·04:00~ 귀속 전부 이 기준.

## 6. 심사·비용 경계
- 권한 0(갤러리). 즉시심사 트랙.
- 무료: 우리 전표·표준 달력(온디바이스). AI 임포트: 하루 N장 무료 → 초과 유료(구독). 게이트=v13~ 심어둔 entitlement 재사용(이중작업 0).

## 7. 단계 (쪼개기)
- **v17-0 (즉시·한 줄 수정·최우선):** 수동 과거기록 **목적지 강제 제거** — `RecordsScreen` 337행 가드를 "금액>0 또는 목적지 있음"으로 바꾸고 빈 목적지는 `미정`으로 저장. **날짜+금액만으로 저장 가능.** (문의 폭주 즉시 해소)
- **v17-a (무료·최우선):** ①마감 전표 → 확인 다이얼로그(날짜 자동제안+[예]/[아니요]) → 그날 소계·합계 기록 + 회사전송 **동시** + 재스캔 멱등(**"회사전송만 됨" 버그 해소**). ②**전표→운행 금액매칭**: 플로팅/GPS 빈금액 운행에 시간매칭으로 **빈칸만 채우기**, 이미 값 있으면 확인만(★계속 요청된 것). 온디바이스.
- **v17-b (무료·최정확):** 다른 앱 **파일(엑셀/CSV) 가져오기** — 열 자동매핑 → 확인 표. ③표준 월 캘린더 이미지 그대로 따오기(격자 인식 보강).
- **v17-c (AI·유료게이트):** 낯선 앱 스샷·**손글씨 노트** → 멀티모달 AI 추출 → 같은 확인 표. 일일 무료한도+구독.
- **v17-d:** 전표 개별거래 → "출발·도착 미정 + 금액" 시간대별 운행 완성(루이 차후 방향).
- **v17-e (영업일 시작 전면적용):** 서버 `/api/trips`·`/api/stats`·`/api/summary`·`/api/expenses`에 `dayStart` 추가 + 앱 기록/월별/통계/마감에서 전송. 야간·일차 기사 장부가 실제로 그 기준으로 묶이게(설정만 있고 미배선인 상태 해소).

## 8. 검증 체크리스트

- [ ] 우리 전표: 개별합=소계=총합계 일치 시 ✅, 불일치 시 경고+[아니요]
- [ ] 같은 22일 전표 2번 스캔 → 그날 1벌만(멱등)
