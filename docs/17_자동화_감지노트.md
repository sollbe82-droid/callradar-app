# 콜레이더 — 자동화 감지 노트 (v6 현장 실측 + 스토어판 설계 결론)
*작성 2026-07-23 · 루이(현직) v6 완전자동판 테스트 실측을 기록 · v15·v16 구현의 직접 참고*

> 목적: v6 접근성 완전자동판에서 실제로 뭘 잘 잡고 뭘 못 잡았는지를 박제해, 스토어 합법판(v15·v16)을 그 지식 위에 짓는다.

---

## 1. v6 실측 (접근성 완전자동판 · 테스터 3명)
- **카카오T / 티머니 ONDA:** "승객탑승" 등 **특정 키워드**로 운행 시작 잘 잡음. 종료 시 **금액도 잘 잡음.** (사실상 100%)
- **우버(Uber):** 시작 때 **목적지가 화면에 안 나옴.** 종료 때 **금액 입력에 약간 버그**(이벤트 파싱 꼬임).
- **배회(길빵):** 콜앱 없이 손 흔들어 태우는 운행 = 플랫폼 없음, 별도 취급.
- 결론: 시작/종료 감지 성공, 금액 자동 95%(카카오·티머니 100%, 우버만 오류).

## 1-B. 플랫폼별 콜 화면 실제 (공유·OCR 관점 · 현장 확인)
- **카카오T:** 목적지 = **텍스트** (시작 화면 or "콜정보" 탭 시 보임) → 스샷에 찍힘, **OCR 목적지 추출 가능.**
- **티머니 ONDA:** 목적지 = **텍스트**, 시작 때 보임 → 스샷·**OCR 가능.**
- **우버:** 목적지 **텍스트 없음 = 지도 한 장** → 스샷엔 지도(방향·지역은 보임), **OCR로 목적지 텍스트 추출 불가** → 목적지는 **GPS 도착좌표→동**으로 대체. (단, 종료 요금화면 금액은 숫자라 OCR 정상)
- **공유 함의:** 스샷 이미지는 다 됨(카카오·티머니=목적지 텍스트, 우버=지도도 방향 정보로 유효). 구조화 목적지 텍스트만 우버가 빠짐.
- **채택 포인트(중요):** 기사들이 **이미 콜 스샷을 손으로 오픈방에 올리는 중** → v14는 그 습관을 **1탭+자동 워터마크+자동 전송**으로 바꾸는 것(새 습관 강요 아님). 브랜드 자동 노출 = 바이럴.

## 2. 스토어판 설계 결론 (접근성 없이 같은 결과)
- **시작:** 화면 키워드 스크래핑 대신 **GPS(지오펜스+활동인식)로 자동 감지.** (v16)
- **종료:** **버튼 1탭 → 화면 스샷 → OCR로 금액 잡음.** 화면에 뜬 숫자를 그대로 읽어서 **v6 우버 금액버그가 사라짐.** (v15)
- **플랫폼 판별 (시작 때 로고 스샷 인식은 불안정 → 안 씀):**
  1. **기기별 플랫폼**(이미 구현) — 서브폰=우버로 박아두면 detection 불필요. (2·3폰 유저 최적)
  2. **한 폰 다중 플랫폼** → **종료 스샷에 금액과 함께 뜬 플랫폼 텍스트**로 태그.
  3. **콜앱 감지 안 됨** → **길빵** 기본.
- **핵심 단순화:** 스샷은 **종료 때 한 장**이면 됨 → 그 한 장이 **금액 + 플랫폼**을 동시에 준다. 시작 스샷 불필요.
- **목적지:** v6는 앱에서 긁었지만, 스토어판은 **GPS 도착좌표 → 역지오코딩(동)**으로 대체(정확한 상호명은 포기, 동 단위면 충분).

## 3. 유저 마찰점 (신경 쓸 것) + 완화
- **화면공유 동의 1회/근무** (안드로이드 규칙). "스샷 찍을 때만 쓰고 딴 건 안 본다"를 앱에서 명확히 안내.
- **하차 때 요금 화면이 떠 있어야** 스샷이 금액을 잡음 → "내릴 때 요금화면에서 버튼 탭" 습관(= v6도 유사).
- 체감: 근무 시작 1회 동의 + 하차마다 1탭 → **거의 자동**, v6 근접.

## 4. 금액 OCR 규칙 (특허 발명2 · 기존 ReceiptOcr 재사용)
- 콤마 금액 우선, **복수 금액 중 최대값 = 실요금**, 미션·프로모션·지급안내 금액 필터, "미터기 요금 14,400"식 통화단위 생략 인식, 연도(2000~2099) 제외.
- 우버 특례 화면(isUberFareScreen) 보정 → 95%→100% 목표.

## 5. 특허 연결
- 발명1(무입력 자동수집·트립 종료판별) · 발명2(금액 정규화·최대금액·통화생략·다중소스) · 발명7(정보제공·무자동수락). **접근성→GPS/캡처로 방식만 바뀜, 권리 안.**

## 6. 구현 매핑
- v15 = §2 종료 스샷 금액+플랫폼 + §4 OCR(우버 100%).
- v16 = §2 시작 GPS 자동 감지(지오펜스+활동인식).
- 기기별 플랫폼 = 이미 구현(v12 페어링).
