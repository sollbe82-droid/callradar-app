# docs/28 — 콜레이더 기사 디지털 명함 (단골 확보 · 유료 킬러 기능)

작성: 2026-07-26 · 상태: 설계(제안)

## 왜 (전략)
다른 택시앱은 "정산/기록"에 머문다. **기사를 브랜딩해 단골을 만드는 도구**는 비어 있다.
공항·장거리·외국인 손님은 "이 기사 또 부르고 싶다"가 곧 매출. 명함 = 재콜 장치.
→ 기사 매출에 직접 기여하므로 **유료 전환 근거가 분명한 킬러 기능**이 될 수 있음.

## 무엇 (기능)
기사별 **디지털 명함**을 만들고, 손님이 **한 번 탭으로 연락처 저장·SNS 추가**하게 한다.

### 명함 구성
- 이름/닉네임, 차량번호, 사진(선택), 한 줄 슬로건("안전운행 20년 · 친절 보장" 또는 명언)
- 다국어(한/영/중/일) 자동 표시 — 회화카드의 번역 기능 재활용. 예: "I drive safely. Call me again!"
- 연락·SNS 버튼: 전화, 카카오채널/오픈챗, 카카오페이(팁), 위챗(ID/QR), 인스타, 페북 — 있는 것만 노출
- QR 코드 (핵심): 스캔 시 vCard 저장 + 웹 명함 링크

### 손님 동작(현실적 최선)
- **연락처 저장**: QR/링크에 **vCard(.vcf)** → 손님 폰이 "○○○ 기사님 연락처에 추가?" 팝업(원탭).
  - ※ 몰래/강제 저장은 OS가 금지(개인정보). "원탭 저장"이 저장률·거부감 모두 최적.
- **SNS 추가**: 딥링크로 카카오채널 추가/위챗 QR/인스타 팔로우 — 각 **한 탭**.
  - ※ 완전 자동 친추는 각 플랫폼이 스팸방지로 차단. 원탭이 정책상 안전.
- 하차 시 **전체화면 QR** "찍어주세요" 모드.

### 개인정보/안전
- **노출 항목 선택**(전화 숨기고 카카오채널만 등), 기본은 "전화 숨김·채널 우선".
- 명함 링크에 개인 식별정보 최소화, 만료/비활성 토글.

## 단계 (로드맵)
- **v1 (앱 내, 서버 최소)**: 명함 편집 + QR(vCard 포함) + 이미지로 저장·공유. 오프라인도 됨.
- **v2 (웹 명함)**: `call-radar.app/c/{기사코드}` 페이지(앱 없이 손님이 봄) + 다국어 + SNS 원탭.
- **v3 (수익·연동)**: 카카오페이 팁, 위챗 연동, 방문 통계(몇 명이 저장했나 — 기사 동기부여).

## 수익화 (유료 근거)
- 무료: 기본 명함 1종.
- 유료(프로): 사진·테마·다국어·웹명함·QR 무제한·방문 통계·"광고 없는 명함".
- 단골 1명 재콜 = 유료값 회수 → 기사 입장에서 ROI 명확.

## IP / 특허 (참고용 — 변리사 상담 필수)
> ⚠️ 저는 변리사·변호사가 아닙니다. 아래는 일반 정보이며, 실제 출원은 **변리사(특허사무소) 상담**이 필요합니다.

- **"디지털 명함" 자체는 신규성 없음**(vCard·명함앱 다수 존재) → 넓은 특허는 어려움.
- 특허는 **신규성 + 진보성(비자명성) + 기술적 성격**이 필요. 소프트웨어/영업방법 특허는 한국·미국 모두 문턱이 높음.
- 그나마 **구체적·신규한 "방법(method)"**으로 좁히면 가능성: 예)
  - 운행 컨텍스트(공항/장거리/외국인 감지)에 따라 **명함 언어·문구를 자동 구성**하고, 하차 시점에 **QR-vCard + SNS 원탭 추가를 단일 플로우로 유도**하는 방법.
  - 손님 저장/재콜 이벤트를 기사 리텐션 지표로 피드백하는 시스템.
- 실무 팁:
  1. **공개 전 주의**: 구체적 신규 방법은 공개(스토어 출시·상세 블로그) 전에 **가출원(임시명세서)**으로 우선일 확보 고려. (한·미 공지예외/유예기간 있으나 의존은 위험)
  2. **가출원(Provisional/국내 가출원)**은 비용이 낮아 우선일 선점에 유용.
  3. 청구항은 **일반 아이디어가 아니라 특정 기술적 방법**으로.
  4. 현실적으로는 **빠른 실행 + 브랜드 + 데이터(단골 네트워크)**가 약한 특허보다 강한 해자일 수 있음. 특허는 보조.
- 다음 액션(원하면): 변리사 상담 전 **발명 요지 1페이지**(무엇이 새로운가·기존과 차이·구체 플로우)를 제가 정리해 드릴 수 있음.

## 재사용 자산
- 번역: AirportScreen의 translateAll(한→영/중/일) 이미 있음.
- 공유/이미지: 캡처·공유(v18) 인프라 재활용.
- 서버: users 테이블 + 명함 프로필/코드 컬럼, 웹 라우트.

## 열린 질문
- 웹 명함 도메인/호스팅(Render 정적 라우트로 가능).
- 유료 결제 수단(구글 인앱결제 vs 외부).
- 명함 코드 체계(짧은 코드 vs QR 토큰).
