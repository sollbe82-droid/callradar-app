# 구글플레이 거부 대응 — 스토어 설명에 접근성 고지 넣기

**거부일** 2026-08-31 · **트랙** 비공개 테스트 Alpha (v98 / 2.9.8)
**사유** "Play 스토어의 앱 설명에 AccessibilityService API 사용이 반영되어 있지 않으므로 앱을 승인할 수 없습니다."

## 먼저 — 이건 반려가 아니라 서류 미비다

구글이 지적한 건 **등록정보(스토어 설명) 한 곳**이다. 정책 위반이라고 하지 않았다.

- 접근성 **사용 자체를 거부한 게 아니다.** 메일이 나열한 금지 항목(설정 무단 변경·제거 차단·
  개인정보 알림 우회·UI 조작·통화 녹음) 중 우리가 해당하는 건 **하나도 없다.** 정책 전문을
  붙여준 것뿐이다.
- **프로덕션은 안전하다.** "이전 버전의 앱이 있는 경우 Google Play에서 계속 제공됩니다" —
  v97(접근성 없음, 117명)은 그대로 돌아간다. 정관의 '프로덕션 직행 금지' 방침이 실제로 지켜졌다.
- 앱 안 고지화면(`AutoRecordConsentActivity`)과 선언서·영상은 이미 통과했다. **설명만 비어 있었다.**

## 넣을 위치

Play Console → **스토어 등록정보(기본 스토어 등록정보)** → **전체 설명**
→ 아래 블록을 **맨 위**에 붙인다. 구글은 "명확하고 눈에 띄게(prominently)"를 본다.
기존 설명은 그 아래에 그대로 둔다.

## ★ 붙여넣을 문구 (전체 설명 맨 위)

```
[접근성 서비스 사용 안내]

콜레이더는 '운행 자동기록' 기능을 위해 Android 접근성 서비스(AccessibilityService API)를
사용합니다. 이 기능은 선택 사항이며, 앱 안에서 내용을 확인하고 직접 동의한 경우에만 켜집니다.

· 무엇을 위해 쓰나요
  택시 기사앱의 운행 화면을 읽어, 손님 탑승·운행 완료·요금을 기사님이 손으로 적지 않아도
  자동으로 기록해 드립니다. 하루 15~20콜을 운행하며 매번 직접 입력하는 것은 현실적으로
  어렵기 때문에, 이 기능이 콜레이더의 핵심입니다.

· 어떤 앱을 읽나요
  카카오T 기사용, 우버 드라이버, 티머니GO 기사용, 티머니GO 내비게이션 — 이 네 개뿐입니다.
  대상 목록은 앱에 고정되어 있어 다른 앱의 화면은 기술적으로 읽을 수 없습니다.

· 무엇을 읽나요
  운행 상태(배차·탑승·완료·취소)와 요금 금액입니다.
  승객의 이름·전화번호 등 개인정보는 읽지도, 저장하지도 않습니다.

· 하지 않는 것
  화면을 캡처하거나 녹화하지 않습니다.
  회원님을 대신해 앱을 터치하거나 조작하지 않습니다 — 읽기만 합니다.
  읽은 내용을 광고에 쓰거나 제3자에게 판매하지 않습니다.
  위 네 개 앱 외의 다른 앱은 읽지 않습니다.

· 끄는 방법
  앱의 홈 화면에서 '자동 기록' 을 끄거나, 휴대폰 설정 > 접근성 > 설치된 앱 > 콜레이더 에서
  언제든 해제할 수 있습니다. 꺼도 나머지 기능(수동 기록·정산·통계)은 그대로 사용합니다.

콜레이더는 장애인 지원을 위한 접근성 도구가 아니며, isAccessibilityTool 로 선언하지 않습니다.
```

## 왜 이렇게 썼나

- **앱 안 고지화면(`AutoRecordConsentActivity`)·접근성 설정 설명문(`accessibility_service_description`)과
  문장을 일치시켰다.** 구글은 영상·앱내고지·등록정보 셋을 대조한다. 어긋나면 허위 고지가 된다.
- "네 개 앱" 을 **이름까지** 적었다. `packageNames` 에 박힌 네 개와 정확히 같다
  (`com.kakao.taxi.driver`, `com.ubercab.driver`, `kr.co.tmoney.tia`, `com.thinkware.inaviair.tmoney`).
- **"읽기만 하고 조작하지 않는다"** 를 명시했다. 2026년 신설 조항이 막는 건 앱이 스스로 판단해
  행동을 실행하는 것인데, 우리는 거기 해당하지 않는다는 점이 이 한 줄이다.
- **"핵심 기능"** 이라고 못 박았다. 구글이 요구하는 건 부가 기능이 아니라 core functionality 설명이다.
- **끄는 방법**을 넣었다. 사용자가 기능을 끌 수 있어야 한다는 정책 요건이다.
