## 보안(v22) 실기기 확인
- 모든 추가·삭제가 **토큰 인증(Authorization: Bearer)** 으로 서버 반영됨 → phase-1 IDOR 방어 라이브 정상.
- 요금수정·삭제 소유자 검증(phase-1b) 본인 계정에서 정상 동작.

## 데이터 무결성 (유령/중복 재확인)
- 30건 저장 → 정확히 30건, 합계 원단위까지 일치 → **입력→저장→서버 동기화 무손실.**
- 삭제 시 건수·합계 정확히 감소 → 유령/중복 없음.

## 아직 안 한(추가로 할 수 있는) 테스트
- 경계값/이상입력: 0원, 음수, 오버플로우(초대형), 빈값, 한글·특수문자 (동기화 안정 위해 이번엔 유효값만 사용)
- 수정(금액 변경) 경로
- 지출(비용) 입력 탭
- 기사 설정 옵션 변경(수수료·사납금 등)
- 운행 시작→종료 플로팅 전체 플로우
- 가져오기(영수증/마감 파싱)
