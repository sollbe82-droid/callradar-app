## 2. 유료 구독 설계

### 원칙 — 데이터를 모으는 기능은 영원히 무료

콜레이더의 자산은 기사들의 기록입니다. 기록을 막으면 자산이 안 쌓입니다.
**기록은 공짜, 해석은 유료**가 유일하게 말이 되는 구조입니다.

### 가격

**월 4,900원** (연 49,000원 — 2개월분 할인)

근거:
- 기사 하루 매출 20~30만원 기준 **0.02%**
- 인사이트대로 움직여 하루 5,000원만 더 벌어도 한 달이면 15만원
- 카카오T 프로멤버십(월 39,000원)과 성격·가격대가 겹치지 않음
- 경쟁 가계부 앱 대비 유일한 자동기록 + 집단 데이터

### 도입 시점

**MAU 500명 이후.** 지금(112명) 유료화하면 데이터 증가가 멈춥니다.
표본이 얇은 상태에서 인사이트를 팔면 품질 불만만 생깁니다.

그 전까지는 **전 기능 무료 + 후원하기**로 운영합니다.

### 결제 수단

- 인앱결제(구글·원스토어) — 수수료 15~30%, 심사 필요
- 또는 카카오페이·토스 링크 결제 + 앱에서 코드 입력 — 수수료 3% 내외
- 초기엔 후자가 유리(수수료·심사 부담). 규모가 커지면 인앱결제로 전환

## 3. 인프라 — 지금 손봐야 할 것

### 3-1. 서버 (우선순위 1)

| 플랜 | 비용 | 특징 |
|---|---|---|
| **현재: Free** | $0 | 15분 무접속 시 슬립, 월 750시간 제한, **언제든 정책 변경 가능** |
| Starter | 약 $7/월 | 항상 켜짐, 슬립 없음 |
| Standard | 약 $25/월 | 메모리 2GB, 오토스케일 |

**Starter($7)로 올리는 걸 권합니다.** 지금 GitHub Actions로 10분마다 깨우고 있지만, 이건 우회책이지 해결책이 아닙니다.

### 3-2. 데이터베이스 (우선순위 1 — 가장 위험)

**Render 무료 Postgres는 90일 후 삭제됩니다.** 유료 전환 없이 두면 7,859건이 사라질 수 있습니다.

- Render Postgres Starter: 약 $7/월
- 또는 Supabase 무료(500MB, 삭제 없음) / Neon 무료 티어로 이관

**최소한 백업은 이중화해야 합니다:**
- 현재: GitHub Actions 백업 1개
- 추가: 주 1회 로컬 PC로 덤프 내려받기 (`pg_dump`)

### 3-3. 비용 요약

| 항목 | 지금 | 권장 |
|---|---|---|
| 서버 | $0 | $7 |
| DB | $0 (삭제 위험) | $7 |
| AI | $10 한도 | 유지 |
| **합계** | **$10** | **$24/월 (약 33,000원)** |

유료 구독 **7명**이면 인프라비가 나옵니다.
