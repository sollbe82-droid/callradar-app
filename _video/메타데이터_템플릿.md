# 업로드 메타데이터 — 제목 · 설명 · 태그 (자동 생성 규칙 포함)

> 태그는 **500자 제한**입니다. 아래 고정 세트가 약 330자라 그날 태그 3~5개를 더 넣을 여유가 있습니다.

---

## 1. 고정 태그 세트 (매 영상 공통)

```
콜레이더, 택시, 택시기사, 법인택시, 개인택시, 택시운행기록, 택시가계부, 택시수입,
택시매출, 택시앱, 택시기사수입, 카카오T, 카카오택시, 우버택시, 티머니택시,
인천공항택시, 공항택시, 택시콜, 사납금, 택시기사브이로그, 택시노하우, 택시꿀팁,
야간택시, 심야할증, 택시기사일상, 운행기록, 매출관리, 기사님, 택시운전, 택시정보
```

**왜 이 조합인가**
- `택시기사수입` `택시가계부` — 앱 검색 노출과 같은 말을 씁니다(스토어 제목과 일치)
- `카카오T` `우버택시` `티머니택시` — 기사가 실제로 검색하는 앱 이름
- `사납금` `심야할증` — 이 단어를 검색하는 사람은 100% 택시 기사입니다. 정확도가 최고입니다
- `택시기사브이로그` — 이미 큰 카테고리라 추천 영상 옆자리를 노립니다

## 3. 해시태그 (제목·설명 첫 줄용, **3개만**)

```
#택시기사 #택시 #콜레이더
```

> 유튜브는 **앞의 3개만** 영상 위에 표시합니다. 더 넣으면 나머지는 묻히고
> 15개를 넘기면 **전부 무시**됩니다. 3개로 못 박습니다.

그날 **가장 센 숫자**가 앞에 옵니다. 번호(`#12`)는 절대 붙이지 않습니다.

```

       잠실 파장 21:40, 몇 시에 출발해야 하나

       택시 기사 필수 정보!! 꼭 보세요
```
